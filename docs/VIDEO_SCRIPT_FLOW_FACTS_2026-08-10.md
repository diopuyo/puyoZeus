## 2. プロジェクトの目的と目標

- 目的: 上級者対戦 (マスター級以上) の動画から、画像認識+機械学習で有利不利を判定する
- 最終目標: **配信にリアルタイムで載せる評価値オーバーレイ** (OBS対応)
- 本命の狙い: 精度の先にある「**人間が気づいていない評価軸の発見**」
  - 解説の補助は副次的な用途

## 3. 評価の考え方 (将棋AIとの違い・セイバーメトリクス)

将棋AIの評価値との違い:
- 将棋AI = 探索エンジンが自己対局・先読みで局面を評価する (ゲーム内部が完全に見える前提)
- 本プロジェクト = **実際の上級者の対戦とその勝敗結果から学習**した評価
  - 「この盤面は有利」の正解は人が付けず、**試合の結末から逆算** (勝敗は画面の勝利数表示から自動読み取り、人手ゼロ)
  - 148動画・73,416盤面ペア (学習に使用済みは66動画分)

セイバーメトリクスを参考にしている点:
- 野球で「打率より出塁率が勝利に効く」をデータが発見したのと同じ発想
- **人間が「これが重要」と決めない**。観測できる軸 (45指標) だけを用意し、どれが勝敗に効くかはデータに決めさせる
- 形 (GTR・階段) の分類はあえてしない — 「**形は手段、機能が本質**」。測るのは火力・厚み・受けといった「その盤面が何をできるか」
- 実際にデータが教えてくれた例:
  - 「今どれだけ大きい連鎖が組めるか」単独では勝敗はほとんど当たらない
  - 効くのは: おじゃまの差 / 連結の数 / 盤面の密度 / 最大連鎖数の差
  - **局面によって効く指標が入れ替わる**: おじゃま差がない局面では効率系が全滅 (AUC 0.49〜0.50) し色ぷよの量だけが効く (0.538)。おじゃま差が大きいと逆転 (0.65〜0.75)

## 4. 応用や今後の展望

## 5. (後半) 技術部分

認識:
- 精度 **99.54%** (人手正解3,744セルとの突合)。居座り続ける誤りはゼロ (残り0.46%は1秒以内に自己修復する一時汚れ)
- 速度 4.42fps → **31fps** (6施策、全て盤面差分ゼロを検証してから採用)
- 核心設計: 画面はほぼ常に動いている → 状態機械 (安定/ツモ落下/連鎖中/おじゃま落下/演出) を持ち、**盤面が静止した瞬間だけ読み取りを確定**
- 色判定は2方式併用: HSV (速いが光沢に弱い) + 小型CNN (光沢に強いが未学習に弱い)
- 物理法則を検証に使う: 「13段目のぷよは4つ繋がっても消えない (幽霊連鎖)」「おじゃまは6列均等+端数ランダム」「おじゃま7割超の盤面は実戦で安定し得ない」

評価:
- 45指標を0〜1正規化して用意、重要度は勝敗データから学習 (HistGBC、動画ホールドアウトAUC 0.6615)
- 発火した瞬間に判定へ反映 (連鎖終了を待たない)
- 測定器を疑う文化: 測定器自体が壊れていた事故6件以上 → 「精度の主張は測定分布とセット」「層別してから代表値」が恒久ルール
