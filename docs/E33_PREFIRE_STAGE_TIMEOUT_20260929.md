## 実装と時間定数

既存の実測式（23動画418イベント、`chain_id_resolver.py` の根拠）から
段間隔1.17秒を取り、`score_ocr.py` の実測幕間上限0.634秒を丸めた0.65秒と
30Hz観測の式確定2フレームを余裕に加えた。期限は最終段観測から1.886666667秒。
定数は再生前に固定し、結果による変更はしていない。

新段の式を先に処理し、同じ段の再通知では期限を延長しない。
現在式が表示中なら確定を待つ。連鎖側の既存終了信号 `next` / `slide` / `ojama`
が先ならそのフレームで長い候補を除く。全候補消滅時は永久撤回し、従来予測へ戻す。
E32の可視盤面検査・重み・終了原票は変更していない。
