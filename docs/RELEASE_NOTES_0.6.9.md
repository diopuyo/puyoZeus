# puyoZeus Live 0.6.9 — 下書き（候補 A）

公開前に Claude と user が文面を確定するための下書きです。

## 0.6.9 の変更 / Changes in 0.6.9

打ち合い中に、相手の連鎖へどれだけ返せるかの見積もりを見直しました。

- 小さい連鎖で相殺した後も、次のぷよを置いて続けて返せる量を調べます。
- 発火した連鎖の得点を数え始める位置を保ち、同じ連鎖の途中で返せる量がずれにくくしました。
- 見えている NEXT の 2 組を使って、次に置けるぷよを合わせます。
- NEXT の変化の履歴も使い、同じ試合で確認できたぷよの並びから、次に置けるぷよの位置を絞ります。
- 自分がすでに発火した連鎖による相殺を、返せる量へ反映します。
- 相手が長い連鎖を打った時に、こちらが返しを間に合わせられる時間を見直しました。
- 受ける側がすでに発火している長い連鎖の予測も、相殺できる量へ反映します。

この見積もりを使って、打ち合い中の推定勝率を出すモデルを学び直しました。
