## 1. counter_margin反転の根因と修正

元のE14記録を先頭から読み、元映像の同じフレームも確認した。
2613.216667秒の1Pは57個、NEXTは紫黄・黄緑。2613.516667秒には盤面は同じ57個のまま
NEXTが欠測し、続いてNEXTだけが繰り上がる。2613.816667秒に黄・紫の2マスが確定盤面へ
追加され59個となり、NEXTは黄緑・紫紫になる。旧NEXTの紫黄はこの間の操作中の組に対応する。
元記録に操作中の組の専用列はないため、NEXTの繰り上がり・実画像・設置色の収支を照合した。

同じ盤面を固定してNEXTだけを交換する16条件の反実仮想で確認した。
57個盤面＋旧NEXTでは1手応手1,116個、counter_margin +727.286。
同盤面＋欠測NEXTでは1個・−387.714、同盤面＋新NEXTでは5個・−383.714。
59個盤面＋新NEXTでは1,153個・+764.286。受け量は388.714個で共通。
したがって反転の原因は盤面とNEXTの同期ずれである。

色2個の設置収支とNEXT繰り上がりの両方が一致した組だけをcountへ渡す。
NEXT欠測・おじゃま色混入・スライド・片側だけの更新は前回値を保持する。
途中の欠測で対応を失っても、後続の確定観測2点で同じ条件を満たせば同期を取り直す。
通常のおじゃま増加と連鎖終了後の確定盤面は別経路で受理する。
実記録では2612.316667、2613.216667、2613.816667秒に1Pの採用入力が更新される。
`logs/e16/sync_trace.csv` は採用時刻・盤面個数・NEXT・操作中組の推定・保持理由を保存する。

初期版で欠測後の永久保持を発見し、その実行結果は `train_stuck/` と `on_stuck/` に分離した。
最終結果は同期再取得を加えた後の再学習・再生だけを使用する。
なお `NF_k1` は既知NEXT2手＋追加1手の探索値であり、厳密な1手応手量とは異なる。

ここにNF個数・counter_margin・残り手数・1手応手個数の列はない。

## 4. C案の評価と保存

現在層は各側の最新STABLE確定盤面によるG_fe。既存の会計snapshot・NEXTを使い、
仮想着弾や連鎖完走予測盤面への交換は行わない。
予測層は従来経路のS3/landing評価。表示値は既存の `logit_mean` による等重み合成とした。
毎フレーム前回の未合成値へ戻してから評価し、合成を重ねない。

UNKNOWN、予測を超える実測段数/得点、連鎖後の最初の確定盤面との不一致では現在層へ戻す。
盤面照合結果は観測時点以後だけに適用する。段数はシミュレーション値を実測として使わず、
resolverの別名・終了済み実測段数も追跡する。死亡確認後も現在層へ戻す。
`p1_current`、`p1_prediction`、`p1_layer_combined`、`prediction_reasons` をreview CSVに追加。
eventsには区間別 `layers` と全フレームの `events.layers.jsonl` を保存する。

## 最終結果

同一行のCVはlight AUC **0.685127**、log loss **0.635148**（253,335予測）。
重み付きAUCは0.693707、log lossは0.627850。標準モデルAUCも0.687018で、
事前基準のE15 0.702を下回るためCVは不合格。

2612〜2614.08秒の平均1P勝率は **0.270292→0.464086**（62フレーム）で合格。
ただし全62フレームで `prediction_board_mismatch` によって現在層へ戻っている。
この上昇はC案のフォールバックによるもので、同期だけの改善とは区別する。
counter_marginは2613.516667秒に+727.286を保持し、2613.816667秒に+764.286へ更新する。
一方、指定区間全体では2613.216667秒に−388.714→+727.286の反転が1回ある。
設置に伴う応手成立の変化でも事前の「0回」基準は変えず、不合格とする。

A3は2698.983333秒に2Pの死亡を確認し、2699.483333秒を起点とする偽4連鎖の受理が
**1件→0件**（対象1件）になった。2699.5〜2701秒の1P勝率は最小・平均とも
**0.764454**（45フレーム）で0.6以上の基準を満たす。

記録再生3動画のq log lossは **0.582713**（6,526フレーム・有効4試合）で、上限0.5518を超過。
zenchi終盤一致率は **71.9069% = 5,992/8,333** で、下限79.55%に未達。
回避不能死の誤発火は **1/28**、未ラベル0件で基準内。
したがって総合判定は **FAIL**。新フラグはOFFのまま、本番採用しない。
