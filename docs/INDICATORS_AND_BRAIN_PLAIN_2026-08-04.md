# 1. 層1: タイムライン勝率カーブの中身

## 1-1. なぜ45指標ではなく22指標なのか

研究側には45指標があるが、**この動画のカーブが使うのは「盤面の絵だけから計算できる22指標」に絞った第二世代セット**である。理由は設計上の制約で:

- この動画は連鎖中も勝率を止めない (後述のFix B: 連鎖中は「連鎖が終わった後の世界」を仮想的に作って評価する)
- その仮想盤面は純粋なシミュレーション結果なので、**「次に来るぷよ」「経過時間」「手数」の情報が原理的に存在しない**
- だからカーブの全区間を同じ物差しで測るには、そうした文脈を要求しない「絵だけ指標」に限定する必要がある

45指標のうちツモ情報や時間を使うもの (ツモ受け入れ、近未来火力など) はここでは使えない。**公平さのため、通常区間も仮想区間もすべて同じ22指標で評価している**。

## 1-2. 22指標の全リスト (実装から抽出)

| # | 指標 | 測っているもの |
|---|---|---|
| 1 | 色ぷよの総数 | 材料の多さ (「材料=潜在力」の法則に対応) |
| 2 | 一番高い列の高さ | 積みの高さ (序盤の無駄な高さは危険信号) |
| 3 | 列の凸凹 | 隣り合う列の段差の荒れ具合 |
| 4 | 窒息までの余裕 | 死に直結する3列目の空き |
| 5 | 窒息余裕・周辺版 | 3列目の隣の列まで含めた余裕 |
| 6 | 盤面のおじゃま数 | 自陣に埋まっているおじゃまの量 |
| 7 | 今の最大連鎖 | 今発火したら何連鎖か (盤面コピー上で実際に連鎖を再生) |
| 8 | 今撃った場合の火力 | 上記連鎖で相手に送れるおじゃま数 |
| 9 | 連鎖効率 | 全ぷよのうち連鎖に参加する割合 (無駄ぷよの少なさ) |
| 10 | 発火までの残り個数 | あと何個置けば撃てるか |
| 11 | 第二波の構築力 | 本線を撃った後、残りで次を組めるか |
| 12 | 掘り耐性 | おじゃまに埋められても本線を掘り出せるか |
| 13 | おじゃまによる分断 | 埋まったおじゃまが連鎖をどれだけ切断しているか |
| 14 | 本線の連結ペア数 | 本線を構成する同色つながりの数 |
| 15 | 孤立ペア数 | どこにもつながらない浮きペアの数 |
| 16 | 本線連結率 | つながりのうち本線に属する割合 |
| 17 | 受けやすさ | おじゃまを受けた時の崩れにくさ |
| 18 | 伸ばし切り連鎖数 | 埋め切るまで伸ばした場合の連鎖数 |
| 19 | 発火点の数 | 撃ち始められる場所が何箇所あるか |
| 20 | 複数色発火 | 違う色でも発火できる柔軟性 |
| 21 | 副砲の数 | 本線以外の小連鎖の数 |
| 22 | 同時消しの豊かさ | 一度に多く消せる形か |

**各指標は3本ずつ入る**: 自分の値・相手の値・その差。つまりモデルへの入力は22×3=66本。「差」を明示的に持たせているのは、勝負は絶対値ではなく相対で決まるため。

## 1-3. 教材と学習のしくみ

- 教材: 上級者66動画から「同時刻の両者の盤面ペア + その試合の勝敗」を**73,416ペア**取得
- **鏡像複製で2倍にする**: 全ペアの1Pと2Pを丸ごと入れ替えたコピーを追加して146,832行にする。これには理由がある (次項)

### 空盤面52%事件 (鏡像複製が生まれた経緯)

ユーザーの目視レビューで「**試合開始直後の空盤面なのに1P勝率52%から始まる**」という指摘が出た。調査の結果、教材中の671試合でたまたま1P側の勝率が52.0%あり (統計的には偶然の範囲、「1Pが有利になるゲーム上の事情はない」とドメイン確認済み)、モデルがこの偶然の偏りを「1Pは最初から少し有利」と学習してしまっていた。

対策が鏡像複製で、全教材を左右入れ替えたコピーと共に学習させる。すると数学的に「両者が完全に同じ状態なら勝率はきっかり50%」が保証される (対称な入力に対して対称な答えを返すことが損失関数の性質から強制される)。**見た目の1行の工夫だが、証明とテストつきで入れてある**。

### 局面の切り方は「時計」ではなく「埋まり具合」

序盤/中盤/終盤は経過時間ではなく、**両者の盤面の埋まり具合の合計**で3等分する。時間で切ると試合展開の速い遅いに引きずられるため。切った3つの局面ごとに別々のモデルを学習する。

### 言い値の補正

学習した確率は「自信過剰」の癖がある (過去の実測: 80%と言った局面の実勝率64%)。そこで学習に使っていないデータで「言い値→実勝率」の補正曲線を作り、表示前に必ず通す。補正曲線を作るデータと成績を測るデータも分けてある (自分で自分を採点させない)。

# 2. 層2: 発火バッジ (ΔWinProb 速報) の中身

連鎖発火の瞬間に出る「±○○pt」の速報。5段階で計算される:

1. **発火の検出** — スコア表示に現れる掛け算式 (例「30×8」) で「撃った瞬間」を捉える
2. **交換の結果予測** — 二段重ねモデル (実データ学習 + シミュレーション) で「受け側が対応に成功する確率」と「交換後の正味おじゃま」を予測
3. **連鎖後の世界を再構成** — 予測した正味おじゃまを、ゲームの物理ルール通り (まず相殺、残りを6列に均等配分) に両者の盤面へ仮想反映
4. **同じ物差しで2回測る** — 発火前の実盤面と発火後の仮想盤面を、層1と**同じ22指標モデル**で評価し、差分をバッジの±ptにする (同じ物差しなのでカーブと整合する)
5. **表示** — 発火側視点の増減としてバッジ表示

## 2-1. 二段重ねモデルの入力 (何を見て予測しているか)

- **指標の3本組**: 発火時点の「発火側の指標・受け側の指標・その差」一式
- **局面** (序/中/終) と**座席** (1P/2P)
- **シミュレーション3列** (物理の読みを学習に注入する部分):
  - **何手積めるか** — この連鎖が終わるまでの時間で、受け側は何手動けるか (連鎖数→時間→手数の換算。実測較正済み: 1連鎖あたり約0.4秒)
  - **期待反撃おじゃま** — 受け側が返してきそうな量
  - **正味ダメージ** — 相殺後に実際に通るダメージの見積もり

この「実データ学習+シミュレーションの二段重ね」は、実データ単独・シミュレーション単独との三つ巴比較で**全局面で統計的に有意勝ち** (順位相関0.808)、**特に中盤が最強 (0.856)** だった構成をそのまま使っている。

## 2-2. 「K手読み」はどこに居るか (整理)

K手 (何手先まで読むか) 系の部品は3つあり、運命が分かれた:

| 部品 | 中身 | 現状 |
|---|---|---|
| 何手積めるか | 相手の連鎖時間中に自分が動ける手数 | **採用** (バッジの入力3列の1つ) |
| K=4の応手確率 | 受け側が4手以内に返せる確率をサイコロ試行で見積もる | **数値としては棄却** (実戦の応酬は平均13手あり、4手打ち切りは相手の対応力を過小評価する危険な偏りを持つ)。分布の表示専用に格下げ |
| 近未来最大火力 | 理想のツモがK手来たら連鎖をどこまで伸ばし切れるか | **有望のまま棚上げ** (中盤の相関+0.12〜0.17の signal はあるが、4動画・理想ツモ版のみの未確証。かつ層1は「絵だけ」制約でツモ情報を使えないため現行カーブには原理的に入らない) |

## 2-3. 品質検証

- 全66動画の**16,470発火すべて**で計算・検証済み
- バッジは平均±20.8pt動き、発火側が有利になるケース92% (直感と整合)
- 「未来を完全に知っていたら」という神様版との比較 (oracle検証) により、残る誤差の主因は予測モデルではなく盤面復元側にあると切り分け済み
- 検品で「±200ptに二重計上される」バグを発見・修正した上での数字

# 3. 層3: 理論値 (決着インジケータ) の中身

**学習ゼロ**の層。統計ではなく物理の会計で「もう避けられない死があるか」だけを判定する:

- 飛んでいるおじゃまの正確な帳簿 (送った量・相殺・着弾待ち)
- 受け側の防御力の上限見積もり: **手持ちの次ツモ2組をそれぞれ実際に置いてみる22通りの小探索** (構え完成値) で「最大でどれだけ返せるか」をタイトに見積もる
- 防御上限を出しても受け切れない → 「計算上の決着」を表示

サイコロ試行版 (確率分布のp25/p75) も部品として存在するが、判定への合成は数値検証で棄却し**既定OFF・表示検討用**にとどめている。

## なぜ実践値と分けたのか

以前は1つの数字に「統計的にこれくらい勝つ」(実践) と「もう詰んでいる」(理論) が混ざっており、表示の調整が迷走した。根本原因は**意味の違う数字の混在**と診断し、2026-08-04に分離を決定:

- **実践値** (層1+2): 正解は「実際の勝敗」。実況で言えば「経験上こういう試合は8割方あちらが勝ちます」
- **理論値** (層3): 正解は「回避不能な窒息」。実況で言えば「計算上もう受かりません、詰みです」

# 4. 45指標・ニューラルネットとの関係 (研究側の全体地図)

## 4-1. 45指標はどこにいるのか

45指標は**研究・観測用の親セット**で、最新動画の表示には直接は乗っていない (乗っているのは上記の第二世代22指標)。45側の役割:

- どの観測軸が勝敗に効くかの発見装置 (重要度ランキング: 1位「飛来予告おじゃま」0.125で2位の9倍)
- 将来ニューラルネットを本番投入する際の「補助の先生」候補
- 死に指標の証明装置 (火力の生値は無価値 / 形の指標はほぼ無価値 / 飽和天井は空き面積と同じ、など「作らないものリスト」の根拠)

## 4-2. ニューラルネットは2つあり、役割が違う

| ネット | 役割 | 最新動画での状態 |
|---|---|---|
| 目のネット | 盤面の各マスの色の読み取り (色味判別との二重チェック) | **現役で使用中** |
| 頭脳のネット | 盤面→勝率の直接予測 | **不使用** (研究トラック。成績0.607、序盤で手組み指標超えを確認済み) |

最終形では頭脳のネットが主役になり、45指標は教師役に回る。その移行は「目の仕上げ (現在走行中の演出光ゲート効果測定が最後の大物) → 動画100〜150本への拡大」の後、本番化フェーズで行う。
