### おじゃま予告の216頭打ち — 「score OCR異常由来」は誤りだった (訂正 2026-08-18)

収集ログに大量に出る `forecast cap[p1]: 630 > abs_cap=216, clamping` の正体を、
148再収集の走行中に実データで調べ直した結果、**W25対応中に書かれた
「score OCR異常由来のバグ」という説明が誤りだった**と確定した。

#### 何だったのか

**マージンタイム減衰という公式仕様の帰結であり、バグではない。**
試合開始96秒以降は16秒ごとにレートが×0.75で減衰し、下限1まで落ちる
(`src/scoring.py:503-532`、`docs/PUYO_RULES_CONFIRMED_2026-07-22.md:16` で
Puyo Nexus/segabits 準拠を確認済み)。レートが1まで落ちた終盤では点数と
おじゃま個数がほぼ1:1になるため、1,000〜2,000点の中規模連鎖でも生成量が
1,000〜2,000個に達し、3画面分の安全上限216を軽々超える。

実測 (W12ラベルCSV 582,498行 / 81動画): 216で頭打ちになった6,392行のうち
**6,301行 (98.6%) が tsumo 40〜150**、つまりマージンタイム開始以降の妥当な
範囲に収まっていた。2026-07-13 の `docs/ADVANTAGE_OVERLAY_2026-07-13.md:42`
に「forecast 494 暴走は本物のゲーム終わらせ連鎖。cap 216 は致死超で無害」と
既に同じ結論が出ており、今回はその再確認にあたる。

#### なぜ誤った記載が生まれたか (教訓)

W25 対応中に副産物として発見した際、`elapsed` や `tsumo_count` との突合を
一度もせずに「score OCR異常由来」と断定形で書いた。**副産物として気づいた
事象ほど、本筋の作業に押されて検証を省略しやすい**。断定形で書くなら根拠の
数値を併記し、無いなら「未検証の仮説」と明示すること。

#### 学習データへの実害 (148やり直しは不要と確定)

clamp は npz 書き込み**前**に適用されるため、630 や 1945 といった暴走値が
npz に入ることはない (実測でも `ojama_forecast_uncapped` の最大値は厳密に
216.0、216超は0件)。列ごとの影響は次のとおり。

| 列 | 影響 |
|---|---|
| `ojama_net_balance` 系 | **無傷**。独立に `ON_FIELD_CAP=72` がかかるため216の値に依存しない |
| `ojama_forecast` (学習投入列) | **不変**。`raw/72` を0-1に丸めるため72以上はどの値でも1.0 |
| `ojama_forecast_uncapped` / `_log` / `_progress_interaction` | 216を分母として**意図的に使う設計**。216超が1.0に潰れる飽和は実在するが全体の1.10%で、設計文書に既知の限界として明記済み |

発生率は今回の148に限った話ではない。前回148収集では148本中81本 (54.7%)、
W12の50本再収集では50本中50本 (100%) で同じ警告が出ており、**現行の本番
データにも同じ密度で最初から存在している**。「今回歪んだか」ではなく
「元々ずっとこうだった」が正しい前提。

#### 残った小さな本物の異常 (低優先)

`video_c81` (2P, tsumo2-3) と `video_c84` (1P, tsumo1-5) の計7行だけ、
マージンタイム対象外の試合開始直後に頭打ちが起きている (全データの0.0012%)。

短時間で自己修正しており、優先度は最低。

#### 上限引き上げについて

`PENDING_ABS_CAP` を216から引き上げれば残存1.10%の飽和は縮むが、
W12で効果測定済み (216+のズレ 2.87pt→1.21pt、「深刻度は過大評価されていた」

### W27-c: 収集の並列数は14が最適 (2026-08-20 実測、10並列は18%悪化)

バイアスで、時間換算して揃えると 0.82倍だった。

(`scripts/_run_model50v2_2026-08-20.sh`、既定14)。

## W39: dig_resistance のおじゃま端数抽選が OS乱数で、同一入力でも有利不利スコアが実行ごとに最大 ±12.34 点揺れていた (2026-08-25 確定・根治済み)

### 事象 (実測で根因確定)

1. `src/indicators_v2.py` `_dig_resistance_one` が `sim.drop_ojama(board, n_ojama)`
   を **seed 省略**で呼んでいた
2. `src/chain.py` `_calc_ojama_drop_counts` は seed=None のとき
   `random.Random(None)` (OSエントロピー) で端数列を毎回抽選する。テスト
   落下量 10/20/30 個の端数は 4/2/0 なので **10個・20個のケースで落下先が
   毎回変わる**
3. 端数列の違いで落下後盤面の連鎖生存/窒息が変わり `_dig_resistance_one` が
   0.0↔1.0 に反転 → 3量平均の `dig_resistance` が **±1/3 の離散フリップ**
4. `ukeyasusa` は内部で `dig_resistance` を**再抽選** (W_DIG=0.6 → ±0.2 が独立
   に発生)
5. モデル52列中 **4列** (`dig_resistance` / `ukeyasusa` / `diff_dig_resistance`
   / `diff_ukeyasusa`) が汚染。学習データ生成
   (`scripts/build_labeled_win_from_npz.py`) の同4列も収集runごとに非決定

実測 (zenchi 先頭5試合 t=0-420s、母数5186行): `adv_raw` が run 間で
155/5186 行不一致、**最大差 12.34 点**、符号食い違い 45/5186 行。実ゲーム
盤面での `dig_resistance` 300回計算は **0.0 が203回 / 0.3333 が97回の
二峰分布** (`data/verify/adv_nondeterminism_2026-08-25/`)。

### 台帳漏れとしての記録

この乱数は `scripts/build_labeled_win_from_npz.py` (2026-08-13 native化
コメント) に「既存の非決定性はこの載せ替えでは変えない・直さない」と
**注記があるだけで、本台帳に項目が無かった**。8/13 の user 恒久指示
「既知の弱点はあらかじめ潰す (根治 or user承認つきガードを先に決める)」に
対する台帳登録漏れ。既知の非決定性を「注記のみ」で放置した結果、W31 で
GPU 非決定という誤った仮説に調査コストを払った。

### 根治 (2026-08-25 実施)

- `src/indicators_v2.py` `_dig_resistance_one`: 盤面由来の決定論的シード
  `_expected_fire_seed(board) ^ n_ojama` (zlib.crc32 既存規約) を
  `drop_ojama` に渡す
- `scripts/build_labeled_win_from_npz.py` `_native_dig_resistance_one`:
  **完全同一の導出式**で seed を渡す (native/Python パリティ維持 +
  学習データの決定化)
- 再発防止ガード: `src/chain.py` `_calc_ojama_drop_counts` が
  「seed=None + 端数>0」の非決定経路に入ったら RuntimeWarning
  (**既定挙動は不変**、警告のみ)
- 回帰テスト: `tests/test_indicators_v2.py` (seed 配線 + 繰り返し同一値)、
  `tests/test_chain.py` (警告ガード3本)、
  `tests/test_build_labeled_win_from_npz.py` (native 側 seed 配線)

### 副作用の性質

4列の値が「ランダムな1実現値」→「盤面ごとに固定された1実現値」になるだけで
**分布は不変・モデル互換** (再学習不要)。ただし**過去の timeline dump との
bit-identical 比較基準は変わる** (修正前 dump とは一致しない。修正後
run 同士は一致)。

### 残る限界 (根治後も残る、別項)

- 端数落下は依然「単一実現値」の評価 (期待値化していない)。W33 の
  `ojama_damage` 連続量近似のような期待値化は別課題
- `ojama_disruption` (`indicators_v2.py`、seed=i の n_samples 平均) は
  元から決定的で無関係
