# 既知弱点の台帳 (2026-08-13 制定、user指示「既知の弱点はあらかじめ潰しておく」)

## 運用ルール (恒久)
1. **新機能が本台帳の弱点に依存する場合、設計前に「根治する」か「userの明示承認つきで
   ガードで凌ぐ」かを決める**。黙ってガードを積み増すのは禁止
2. 同じ弱点にガードが2つ以上積まれたら、根治の優先度を自動的に引き上げて提案する
3. 事故が起きたら横展開掃索 (2026-08-13方式) をデバッガの定型業務として実施
4. 台帳の更新はコミット必須 (この文書が単一情報源)

## 現在の台帳 (優先度順)

### W1: 認識の連結欠損 → 連鎖シミュレーションの壊滅的過小予測
- **実測**: 真値8連鎖をシミュが1連鎖と判定 (2026-07-30)。高充填盤面の14%に非発火不変条件の破れ
- **積まれたガード (4つ)**: 重力違反の安全弁 / 観測超過時の再決着 / E[最終連鎖|N]の条件付き分布 / テロップ×得点の二重照合
- **根治**: 確定盤面の連結完全性の向上 = 99.99%バックログの一部 (誤り1/50化)。
  部分根治として「発火直前盤面の物理検証強化」は多数決窓+scoped_exitで前進中
- **根治コスト**: 大 (認識本丸)。ただし部分根治の効果測定を148後の物差しで実施

### W2: score OCR の脆弱性 (桁誤読・非試合混入)
- **実測**: 完全破綻動画4本。大連鎖直後の桁誤読が試合境界誤検知→カウンタリセットを誘発
- **【訂正 8/13 user伝授】** 「差分の87%が非10倍数=汚染」は誤診の可能性大。
  **連鎖得点=10の倍数 / 落下ボーナス=1点単位 (上限~250)** のため、設置を挟む
  スナップショット間差分が非10倍数なのは正常。正しい物理制約:
  **連鎖アニメ中の得点変化は設置が無いので純粋な連鎖得点=必ず10の倍数**、
  連鎖外の変化は≤~250 (例外=全消し2100)。取り逃し測定v2はこの層別で再設計
- **積まれたガード**: 壊れ動画隔離 / 全消し判定の上限バンド / 会計のscore整合チェック
- **根治**: 「連鎖中は10の倍数」制約を読み取り補正の事前知識に + 信頼性の層別
  (連鎖中/外で分けて測る)
- **根治コスト**: 中 (数日)。**148再学習後の最優先候補**

### W3: テンプレート類の単一ソース採取
- **実測**: れんさテロップのテンプレが採取元以外で全滅 (C-1a、解決率0%)
- **教訓**: テンプレ・較正値は最初から複数動画で採取する規約にする (新規作成時のチェック項目)
- **根治**: タスク#7 (テンプレ複数採取) で対処中

### W4: フレーム数ベース定数の残り (SEC化未完)
- **実測**: stride/fps次第で実時間の意味が変わる構造欠陥。棚卸し表あり (2026-08-13)。
  会計の内部時計2倍速も同根
- **積まれたガード**: 多数決窓 / entry_hardening のSEC化 (部分)
- **根治**: 生カウンタ定数の全面SEC化 + 会計カウンタ修正 (フラグ式+全域バックテスト)。
  大整理キューに登録済み、148後に実施

### W5: 記録タイミングの側依存 (収支バイアスの根)
- **実測**: 2026-08-13決着。分析時再同期で部分対処 (-21.7%)
- **根治**: 側非依存の密な会計記録列 (次回収集/Phase Jから設計採用、決定済み)

### W7: 疑似ChainEventのスコア0固定 (2026-08-13夜 発見・根治着手)
- **実測**: 連鎖検知3経路のうち formula/landing の2経路が、simulate済み結果を持ちながら
  total_score=0 をハードコード。全連鎖の6.14%が該当、43.8%が4秒以上未確定、
  36.6%は永久未確定。CHAIN保持定数の過小 (0.3秒/連鎖 vs 実測0.5秒+) が再発火ループを併発
- **実害**: 先読み評価 (#9) の起動ゲートが両者発火場面で開かない / 「score=0の
  cc=8」を幻連鎖と誤認する回帰テストまで書かれた (score未計算と連鎖不在の混同)
- **根治 (即実施)**: ①formula/landing の発火時に calculate_chain_score(検証済み結果) を充填
  ③先読み評価のトリガーをsimulate検証済みchain_count併用に
- **チケット (バックテスト必須)**: ②CHAIN保持定数の実測ベース再較正 (cycle71系への回帰リスク)
  ④「連鎖中の差分は10の倍数」制約によるクロスチェック層 (W2の制約を再利用)
