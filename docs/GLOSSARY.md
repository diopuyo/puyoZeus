# 用語集 (有利不利オーバーレイ / 指標 v2)

本プロジェクトで使う専門用語の説明。評価軸・単位の詳細は
`docs/EVALUATION_AXES.md` を参照。

## 有利不利オーバーレイ(判定システム)
| 用語 | 説明 |
|---|---|
| 有利不利(スコア) | 局面がどちらに有利か。−100(2P圧倒)〜+100(1P圧倒)、0=互角 |
| 4成分ブレンド | 有利不利 = 0.35×圧力 + 0.30×得点リード + 0.20×現モデル + 0.15×火力threat |
| 圧力 / PressureTracker | 相手盤面のお邪魔増加(=攻撃着弾)を減衰累積した"通ったダメージ"の記憶。着弾を数秒覚える |
| 得点リード / ScoreLeadTracker | 両者の現在スコア差(=どちらが多く攻撃を通したか)。発火→着弾ラグを橋渡し |
| 現モデル | tier1指標の差分を入力にした学習モデル(HistGBC)の盤面評価 |
| 火力threat | 「相手より大きい撃てる火力を構えているか」= 到達火力(reach)の差 |
| EMA(平滑) | 指数移動平均。有利不利の値を時間方向に滑らかにする |
| HeavyAdvCache / ThreatTracker | 重い盤面計算(current_max_chain, reach等)を~0.3秒毎にキャッシュして高速化する仕組み |

## 火力・連鎖系(指標)
| 用語 | 説明 |
|---|---|
| 連鎖 | ぷよが連続で消える回数。多いほど大火力 |
| 発火 | 連鎖を起動すること。撃つ=発火 |
| 即時火力 (immediate_fire_power) | 今の盤面から最良の1個追加で撃った時の送出お邪魔数 |
| 到達火力 (reach_fire_power) | 実際の次/次々ツモを2手使って到達できる最大火力(=実際に撃てる火力) |
| 潜在火力 (potential_fire_power) | ツモ非依存で「理想ぷよを最大2個足したら組める最大連鎖」。理論上の仕込み量(過小評価バグあり、有利不利には未使用) |
| 現在最大連鎖 (current_max_chain) | 今すぐ組める最大連鎖数(安価な火力指標) |
| 発火準備度 (min_puyos_to_ignite) | あと何個で発火できるか。近いほど1に近い(撃てない大連鎖を割り引く係数) |
| takapt(定石) | 「各列に1色1個落として最良を探す」火力推定の定石(先行研究由来) |
| 本線 | 主砲となるメインの連鎖 |

## お邪魔・会計系
| 用語 | 説明 |
|---|---|
| お邪魔(ぷよ) | 相手の連鎖で送られてくる邪魔ぷよ(盤面値=9) |
| 盤面お邪魔数 (board_ojama_count) | 今盤面に見えているお邪魔の数(直接認識・信頼度高・勝敗最強予測因子) |
| お邪魔会計 (OjamaAccountingTracker) | スコア差→お邪魔換算、相殺、予告、収支を追跡する会計モデル |
| 予告 (forecast) | これから降ってくる保留中のお邪魔数(まだ着弾していない予測値) |
| 着弾 | 予告お邪魔が実際に盤面へ落ちること。発火→着弾に数秒ラグがある |
| 相殺 (offset) | 自分の連鎖で、自分に向かう予告お邪魔を打ち消すこと |
| net収支 (net_balance) | 相殺後の正味お邪魔収支(±72で上限) |
| 端数 (leftover) | お邪魔換算の余り得点の繰越 |
| マージンタイム | 試合経過で送出レートが上がる(少ない得点で多く送れる)時間帯 |
| 掘る | お邪魔の下の色ぷよを消して掘り返すこと |

## 認識・状態系
| 用語 | 説明 |
|---|---|
| STABLE | 盤面が静止した確定状態。指標評価はこの時のみ行う |
| confirmed_board | 確定した盤面(非STABLE中は直前STABLEを凍結) |
| 状態機械 | STABLE/TSUMO_FALL/CHAIN/OJAMA_FALL 等を判定する仕組み |
| 窒息 | 3列目(index2)最上段が埋まると負け |
| 窒息余裕 (death_margin) | 窒息までの余裕(段) |
| 連結 (conn) | 同色が繋がった塊。2連結/3連結の数が連鎖の種 |
| ツモ | 操作する2個1組のぷよ。手数=置いたツモ数 |

## 統計・モデル・運用
| 用語 | 説明 |
|---|---|
| tier1 / tier2 | tier1=単純観測指標、tier2=それを素材にした派生・合成指標 |
| HistGBC | ヒストグラム勾配ブースティング分類器(非線形学習モデル) |
| OOF AUC | Out-of-Fold の AUC。未学習データでの判別性能(0.5=偶然、1.0=完璧) |
| GroupKFold | 動画単位で学習/検証を分ける交差検証(データ漏れ防止) |
| 対称化 | 差分反転+ラベル反転で「互角=50%」の反対称モデルにする学習手法 |
| 汎化 | 学習外データでも通用すること |
| 勝者一致率 | 各ゲームの最終有利不利符号が実際の勝者と一致した割合 |
| リーク | 学習に使った動画で評価してしまう不正(除外で防止) |
| working state / ロールバック点 | 各コミットが「動く状態」で、後から任意点へ戻せる区切り |
| ΔWinProb | 勝率の変化量(局面評価の主ターゲット候補、野球のWPA相当) |
