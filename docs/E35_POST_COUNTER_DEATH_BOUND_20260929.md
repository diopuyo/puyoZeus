# E35: 打ち返し後の死亡上限

## 実装

既定OFFの `--post-counter-death-bound` を追加する。採用設定は変更しない。
入力は死亡専用台帳の相殺後残量と完走予測盤面。複数盤面は全候補を検査し、全候補が死亡するときだけ断定する。
単独の予測盤面が欠測、攻撃量未検証、UNKNOWN、浮遊、試合4色未確認の場合は新機構で断定しない。

- 現在のNEXT/NEXT2を使い、その後は確認済み試合4色の全組合せを許す。
- 列高より上の空きマスと同色群を連結し、置き足しで初消去できる可能性を上から評価する。
- 初消去が可能なら、消去で開く後続色を取りこぼさないよう盤面全色を上限に含める。
- 消去可能数から段数上限と消去配分を動的計画法で列挙し、連結・多色ボーナス込みの得点上限を既存得点規則で算出する。
- 連鎖が不可能で、組ぷよの高さ増加を無視しても次の着弾で全配置が窒息する枝を直ちに証明する。
- それ以外は全配置を進め、実消去数まで火力上限を絞る。同じ色ぷよを次手でも火力として再使用しない。
- 全消し持越しは不明として各発火へ無償付与する。落下点・得点端数の相殺も受け側に有利に丸める。
- 連鎖手は着弾を延期する。非連鎖手だけ最大30個、端数は全列配置を許す。死亡位置は既存 `DEATH_ROW/DEATH_COL` に従う。
- 生存枝・計算予算超過では断定せず、既存死亡探索へ渡す。上限結果は予測層の `unavoidable_death` と既存保持機構へ接続する。
