# ぷよぷよ対戦AI解析プロジェクト 全体まとめ (2026-08-04時点)

専門用語を使わない全体説明。画像認識・技術・統計・指標・現在の状態。

## 何を作っているか

ぷよぷよの上級者同士の対戦動画をコンピュータに「見せて」、**今どちらの選手が何%有利かをリアルタイムで数値表示するツール**です。最終目標はライブ配信画面への重ね表示 (実況の補助になる「形勢グラフ」のようなもの)。単なる表示にとどまらず、大量の試合データから「人間がまだ言語化できていない強さの法則」を発見することも狙っています。

対象は上級ランク (マスター級以上) と確認できた試合のみ。ランク不明の動画は学習に使いません (弱い試合が混ざると法則がぼやけるため)。

## 全体は4段構えの工場

1. **目** — 動画から盤面 (6列×13段のマス目) の各マスの色を読み取る
2. **ものさし** — 読み取った盤面から「強さの手がかり」を45種類、数値として測る
3. **頭脳** — 過去の試合の勝敗データと突き合わせ、「どの手がかりがどれだけ勝敗に効くか」を統計的に学習する
4. **表示** — 学習結果を使って「1P 65%有利」のように画面に出す

現在は1段目「目」の仕上げの真っ最中です。理由は単純で、**目が誤読すると、その上に載る統計も表示も全部信用できなくなる**からです。

## 1. 目 (画像認識) の仕組みと現状

**読み取りの二重チェック**: 各マスの色は「色味・鮮やかさによる判別」と「ニューラルネット (画像から学習した判別器) 」の2系統で読み、突き合わせます。

**一番の工夫は「物理法則を使った状態管理」**: ぷよが落下中か、連鎖の演出中か、静止しているかを常に追跡し、**完全に静止した瞬間の盤面だけを「確定」として採用**します。連鎖中は画面が光ったり揺れたりして誤読の温床なので、その間は直前の確定盤面を凍結して使い続けます。「ぷよは浮かない」「消えたら落ちる」といった物理ルールに反する読み取り結果は捨てます。

補助の読み取り器も複数あります: スコアの数字読み取り、次に来るぷよの読み取り (48回中48回正解)、飛んでくるおじゃまの個数の帳簿付けなど。

**精度の現状**:
- 静止盤面の「ずっと間違え続ける」誤りは、人手で3,744マスを検証して**ゼロ**
- 残る誤りは連鎖直後などの一瞬に出る一時的なもので、1秒以内に自然回復する
- 目標は99.99% (誤りを今の約50分の1へ)。この目標達成が今のフェーズの合格条件
- 処理速度は当初の秒4.4コマから**秒31コマへ7倍高速化**済み (リアルタイム処理の目処が立った)

**今まさに潰している最後の大物**: 相手が連鎖すると「おじゃまが飛んでくる光の演出」が自分の盤面上部に重なり、色ぷよを「おじゃま」と誤認する問題です。盤面がほぼ満杯の局面では、マス誤りの主犯 (誤りの55%) がこれでした。

対策は「演出の光が出ている間は盤面上部の書き換えを一時保留する関所」です:

- 第1弾 (時間だけで判断する方式) は**逆効果で不採用** (誤り47マス→53マスに悪化)。正直に失敗と記録しました
- 第2弾 (今日完成) は**4つの条件が全部揃った時だけ保留**する方式: ①相手が連鎖中か直後 ②自分は連鎖中でない (自分の連鎖表示と混同しない) ③全消し表示中でない ④画面上部が実際に強く光っている。④の「光っている」の基準値は、人手で正解付けした136枚の画像から「誤検知が1件も出ない値」を較正して決めました
- 本日この実装が完成し、自動テスト全4,159件パス。**効果測定がバックグラウンドで走行中** (31本の動画を読み直し中)

## 2. ものさし (手がかり45種) の設計思想

「GTR」のような**定跡の形の名前では分類しません**。形は手段であって、本質は機能 — つまり「どれだけ火力があるか」「おじゃまを受けても耐えられるか」「相手を急かせる力があるか」を直接数値化します。

もう一つの原則は「**人間が重要度を決めない**」こと。人間は観測の軸を用意するだけで、どの手がかりが何%効くかは学習結果に発見させます。実際、人間の直感に反する結果がいくつも出ています (下記)。

## 3. 頭脳 (統計・学習) の仕組みと成績

- **データ**: 上級者の対戦動画66本から「静止盤面 → その試合の勝敗」のペアを収集
- **検証の作法**: 学習に使った動画と成績を測る動画を完全に分けます (同じ試合の前半で学習し後半でテストするようなズルを防ぐ)
- **成績の読み方**: 「当てる力」は 1.0=完璧、0.5=コイン投げの尺度 (AUC) で測ります

**現状の成績と発見**:

| 局面 | 当てる力 | わかったこと |
|---|---|---|
| 序盤 | 低い | 盤面ニューラルネットが人手の手がかりを大幅に上回る (新発見) |
| 中盤 | 0.68で頭打ち | データを3倍に増やしても伸びない = **静止盤面だけでは中盤は読めない** |
| 終盤 | 0.78 (過去最高) | おじゃまの差が最強の手がかり |

- **効く手がかり**: おじゃまの差、ぷよのつながり、盤面の密度、最大連鎖の差。逆に「火力の生の値」は無価値と判明
- **中盤の壁への答え**: 静止した形ではなく「打ち合いの関係」(相手を急かす・受ける・本線を撃つ) を測る方向へ転換。実データ学習とシミュレーションの合わせ技が全局面で有意に勝つことを16,470件の発火データで確認済み (相関0.808)
- **連鎖の瞬間の速報**: 従来は連鎖が終わってから勝率が動く (遅い) という指摘を受け、**発火した瞬間に勝率を速報する仕組み**を実装済み。平均で勝率が20.8ポイント動く
- **自信過剰の補正**: 「80%有利」と表示した局面の実際の勝率が64%しかない「自信過剰」を検出したため、表示前に統計的な補正をかける設計に
- **勝率の二本立て表示** (直近の決定): 「実践値」(統計的にこの形勢ならこれくらい勝つ) と「理論値」(物理的にもう避けられない死の計算) は意味が違うので、混ぜずに2チャンネルで表示する

## 4. 品質管理の文化 (このプロジェクトの特徴)

**測定器の事故を6件発見・修正してきました**。いずれも「測るための道具が、本番と違う条件を測っていた」類のもので、例えば: 成績計算の近似式が間違っていて実力0.516を0.630と過大報告 / 動画のコマ間引きが盤面記録を壊す / 1回の連鎖が複数回の連鎖として二重計上 / 試合を決めた最後の連鎖が18.9%の試合で記録から欠落、など。

この経験から生まれたルール:

- 数値を出す前に必ず層別する (全部混ぜた平均は相殺で嘘をつく)
- 修正は「狙ったシーンが直る」+「全域で悪化しない」の両方で初めて合格 (特定シーンへの過剰適合の防止)
- 採否の最終判断は必ず人間の目視レビューを経る
- 動画1本・1例だけの観察では肯定も否定もしない
