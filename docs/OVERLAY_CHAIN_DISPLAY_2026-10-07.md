# 連鎖の進みの表示専用修正（2026-10-07 user承認）

`LiveB3.update` が受け取る当該フレームの `sides[].formula` の左右から、
公式得点表で一意に逆算できる現在段だけを採用する。読取件数・最終予想を
現在段として扱わない。4色・6×13盤面の現行対象で1～19段に対応する。
同一式を連続2観測で確認する（観測間隔の上限0.5秒、低FPS経路にも対応）。
曖昧な式・欠読中は直前の段を保持し、推測による加算は行わない。

内部の `fire_complete` / 再発火でリセットしない。式がなく、STABLE / TSUMO_FALL /
OJAMA_FALL が連続0.5秒観測されたら消去する。試合外・終了ロック・試合境界・
採用開始・認識epoch変更でも消去する。短い終了誤判定から再発火した際も
画面式の絶対段が復元される。真の終了の判別は認識状態に依存し、最大0.5秒の
確認待ちがある。表示のための追加OCR・モデル・学習行の再生成は行わない。

## 公開契約

v1の任意拡張として `evaluations.b3_contents` に以下を追加する。

- `p1/p2.chain_display_step`: 1～19の整数またはnull。表示専用の現在段。
- `p1/p2.chain_display_observed_at_sec`: 最後に式を確認できた観測時刻。消去時null。
- `chain_display_frame`, `chain_display_t_sec`: 表示状態を最後に更新した観測フレーム・時刻。

既存の `frame/t_sec` はB3計算の基準のまま。表示段の更新時刻とは区別する。
`chain_n_steps`、予想連鎖・残り連鎖、全既存キー・値・必須項目は維持する。
表示ページは `chain_display_step` だけを現在段として参照する。
旧DTOやnullでは「—」とし、観測件数へフォールバックしない。
遅延した非同期推論の採用後にも最新観測の表示状態を公開時に合成するため、
表示段は計算結果の古い時刻へ巻き戻らない。
