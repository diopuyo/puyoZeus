> 用語辞書は `docs/GLOSSARY.md`、評価軸の一覧表は `docs/EVALUATION_AXES.md`。
> 本ファイルは「システムを全く知らない人が読んで全体像を掴む」ための通し解説。
> 最終更新: 2026-07-14(ハイブリッド構成 + 勝率較正)

---

## 0. そもそも何をしているか

対戦動画(1P vs 2P)を1コマずつ画像認識して、両者の盤面を数字の表(6列×13行)に
変換し、「今どちらがどれだけ有利か」を **−100〜+100** の1つの数字にまとめて画面に出す。

- **+100 = 1Pの圧勝確定**、**−100 = 2Pの圧勝確定**、**0 = 互角**。

---

## 1. まず「ぷよぷよの勝敗」の基礎

ぷよぷよ対戦は突き詰めると **「お邪魔ぷよの送り合い」**。

- **連鎖**:同じ色を4つ以上つなげて消すと連続で消えて大きな得点になる。
- **お邪魔ぷよ**:稼いだ得点に応じて相手の盤面に邪魔なぷよが降る。相手が埋まって苦しくなる。
- **相殺**:相手からお邪魔が来ても自分も連鎖を撃てばお邪魔同士が打ち消し合う。
- **窒息**:盤面の特定位置(3列目の一番上)が埋まるとその場で負け。

有利不利とは、ざっくり
> **「相手をどれだけ埋められそうか(攻め)」と「自分がどれだけ耐えられるか(受け)」の差**。

### お邪魔の降り方の重要ルール(モデルの核)
お邪魔は撃った瞬間に全部降るのではなく、**連鎖が終わってから、ぷよを置くたびに
5段ぶん(=30個)ずつまとめて降ってくる**。撃った直後は予告置き場に溜まり、少しずつ配送される。

## 2. 有利不利を作る「5つの部品」

```
有利不利 = 0.35×圧力 + 0.30×予告 + 0.20×現モデル + 0.15×火力 + 得点タイブレーク(±15)
```

| 部品 | 重み | 何を測るか | 直感 |
|---|---|---|---|
| **① 圧力** | 0.35 | 相手盤面に**着弾した**お邪魔量を減衰させながら記憶 | 「もう通したダメージ」の実績記憶 |
| **② 予告(配送)** | 0.30 | **これから相手に降る残りお邪魔**(相殺後・30個/ターンで配送) | 「予約された攻撃」。未来のダメージ |
| **③ 現モデル** | 0.20 | 盤面12指標を学習器が採点 | 「そもそも良い形はどっちか」 |
| **④ 火力threat** | 0.15 | 2手以内に**実際に届く**連鎖火力の差 | 「構えている大砲の大きさ」 |
| **⑤ 得点タイブレーク** | ±15上限 | 得点差(結果)で僅差だけ勝者側へ微調整 | 脇役。主役は位置(①〜④) |

- **①と②の違い**:①は**もう降った過去**、②は**これから降る未来**。
- **⑤を脇役にした理由**:得点は「結果」でしかなく、有利不利は「これから何が起こるか
  (お邪魔・盤面)」で判断すべき、というユーザー指摘を反映。

## 3. 「現モデル」が見る盤面12指標(すべて0〜1正規化、1P値−2P値の差で入力)

| 指標 | 平たく言うと | 多いと有利? |
|---|---|---|
| 盤面の色ぷよ総数 | 積んである材料の量 | 状況次第 |
| 最大列の高さ | 一番高い列の高さ | 高すぎ=窒息リスク |
| でこぼこ度 | 列ごとの高さの凹凸 | 大きい=組みにくい(不利) |
| 窒息余裕 | 負け位置まであと何段 | 大きい=耐えられる(有利) |
| 窒息余裕(隣接) | 負け位置の周りの余裕 | 大きい=有利 |
| 現在の最大連鎖 | 今すぐ撃てる最大連鎖数 | 大きい=有利 |
| 2連結の数 | 「あと1個で消える」ペア数 | 多い=伸ばしやすい |
| 3連結の数 | 「あと1個で消える」トリオ数 | 多い=発火しやすい |
| お邪魔収支 | お邪魔の出入り差し引き | +=攻めが優勢 |
| お邪魔予告 | これから降る予告量 | 相手側に多い=有利 |
| 盤面お邪魔数 | 今乗っているお邪魔 | 自分に多い=不利 |
| 掘り耐性 | 埋もれても掘り返せる形か | 高い=しぶとい(有利) |

## 4. 「火力」の指標(似ているが別物)

| 種類 | 意味 | 使い所 |
|---|---|---|
| 即時火力 | 今この瞬間に撃てる火力 | 現状把握 |
| **リーチ火力** | **2手以内に実際に置いて届く**火力 | ④threatに採用 |
| ポテンシャル火力 | 理想的に組めた場合の火力(過小になりがち) | 参考のみ |
| 最大連鎖数 | 今組める最長の連鎖段数 | ③現モデルの一要素 |

「理想論より“実際に届く火力”の方が有利不利に効く」ため、リーチ火力を主役にした。

---

## 5. お邪魔会計(②予告の裏側)

- **生成**:連鎖得点 ÷ レート(通常70点=1個)で発生お邪魔量を計算。
- **相殺**:自分と相手の連鎖がぶつかったぶんを打ち消す。
- **配送**:余ったお邪魔を相手の予告へ乗せ、ぷよを置くたびに30個ずつ降らせる。
- **試合境界リセット**:スコアが大きく下がったら次の試合と判断して帳簿リセット。

---

## 6. 画面表示になるまで

```
動画1コマ
  → 画像認識で 1P/2P の盤面を数字の表に変換
  → 5部品(①圧力 ②予告 ③現モデル ④火力 ⑤得点)を計算
  → 重み付き合計 → ±100で頭打ち → EMAで平滑化
  → 有利不利バー + 勝率 + 主因テキスト を描画
```

- **上部バー**:左右どちらに伸びているかで有利側が一目でわかる。
- **勝率%**:有利不利を割合に直したもの(較正については §7)。
- **主因テキスト**:その瞬間、5部品のどれが一番効いているか。
- **下部グラフ**:将棋の評価値グラフ風の時間推移。

## 7. 「勝率%」の作り方と較正(2026-07-14 改善)

初期版は `勝率 = 50% + 有利不利 ÷ 2` の**直線変換**だった。これだと決着済みでも
勝率が70%程度で頭打ちになり「ほぼ勝ちなのに相手に30%残る」という違和感があった。

改善として、実際の対戦結果に当てはめた**ロジスティック曲線**で
有利不利→勝率を変換する(較正)。決着局面が自然に高い勝率へ張り付くようになる。

- 較正パラメータ: `data/indicators_v2/winprob_calib.json`
- 較正ファイルが無い場合は従来の直線変換にフォールバック(後方互換)。

### 較正でも残る限界(今後の課題)
- **静止指標は「飛んでいる決定打」が見えない**:巨大連鎖が実行中でも着弾するまで
  盤面指標は「普通」に見え、リアルタイムで動くのはスコアだけ。決着確定〜着弾の
  10〜15秒間、有利不利が中くらいで止まる。→ 発火基点の near-future 信号が必要。
- **kill判定**:降るお邪魔量 > 受け側の耐えられる量、なら勝率を100%側へ押す判定は未実装。
