# 評価軸・評価単位 リファレンス (有利不利オーバーレイ / 指標 v2)

現状の有利不利判定で使う評価軸と単位。用語説明は `docs/GLOSSARY.md` 併読。

## 0. 評価の前提・単位(全体条件)

| 項目 | 内容 |
|---|---|
| 評価対象 | **両者 STABLE(静止確定)時の盤面のみ**。連鎖中・落下中は直前STABLEを凍結し評価しない |
| 盤面単位 | 6列×13行の配列(可視12行×6列 = **72セルが上限**)。色: 0空/1赤/2青/3緑/4黄/5紫/9お邪魔 |
| 特徴の取り方 | すべて **「自分 − 相手」の差分**(有利不利は相対で決まるため) |
| 時間単位 | フレーム(30fps)/ 秒。会計はフレーム毎に駆動 |
| ゲーム単位 | スコアの大幅リセットで1ゲームに分割 |
| 位相の単位 | 手数(tsumo=置いたツモ数)、または盤面ぷよ数 |
| 最終ターゲット | 現状 = **試合の最終勝者(二値0/1)**。将来 = 時点別勝率変化 ΔWinProb(予定) |

## 1. 上位の評価軸 — 有利不利の4成分(各 −100〜+100)

`有利不利 = 0.35×圧力 + 0.30×予告(リアルタイムincoming) + 0.20×現モデル + 0.15×火力threat`

| 評価軸 | 重み | 単位・算出 | 意味 |
|---|---|---|---|
| 圧力 | 0.35 | 相手盤面お邪魔の増加(個)を減衰累積 → ±100 | 実際に着弾したダメージの持続記憶 |
| 予告(リアルタイム) | 0.30 | 相手の実行中連鎖の規模(score増分/70=incoming個)を自incomingに加算・減衰(半減期~11.5s)+試合境界クリア → ±100 | これから相手が受けるダメージ(位置)。旧「得点リード(結果=累積スコア差)」を2026-07-14に置換 |
| 現モデル | 0.20 | 下記tier1差分 → 学習モデル勝率 → (p−0.5)×200 | 盤面の位置評価(密度・危険・連結等) |
| 火力threat | 0.15 | (自到達火力−相手到達火力)(個)×0.22 → ±100 | 大きい撃てる火力を構えているか |

お邪魔換算 = 連鎖得点 ÷ レート(標準70点で1個)。レート = マージンタイム後は減少。

## 2. 現モデルの入力 = tier1指標(生単位 → 0〜1正規化)

すべて「自−相手」の差分でモデルに入る。

| 指標 | 生の単位 | 正規化 | 意味 |
|---|---|---|---|
| 色ぷよ総数 (board_color_puyo_total) | 個(0〜72) | /72 | お邪魔除く色ぷよ数=土台の厚み |
| 盤面お邪魔数 (board_ojama_count) | 個(0〜72) | /72 | 盤面のお邪魔数(勝敗最強予測因子、多いほど不利) |
| 最大列高 (max_column_height) | 段(0〜12) | /12 | 一番高い列。高いほど窒息に近く不利 |
| 列の凸凹 (column_bumpiness) | 隣接列高低差の合計 | /60 | 表面のばらつき。大きいほど組みにくい |
| 窒息余裕 (death_margin) | 段(12−3列目の高さ) | /12 | 窒息列(index2)の残り余裕。大きいほど安全 |
| 窒息余裕(近傍) (death_margin_neighbor) | 段(12−中央3列の最大高) | /12 | 窒息列周辺の余裕 |
| 現在最大連鎖 (current_max_chain) | 連鎖数 | /19 | 今すぐ組める最大連鎖数(安価な火力) |
| 2連結数 (conn_pair_count) | 組(個数) | 生カウント | 2つ繋がった同色=連鎖の種 |
| 3連結数 (conn_triple_count) | 組(個数) | 生カウント | 3連結=発火寸前 |
| お邪魔純収支 (ojama_net_balance) | 個(±72上限) | score化 | 相殺後の正味収支(プラス=1P攻勢) |
| お邪魔予告 (ojama_forecast) | 個 | score化 | これから降る保留お邪魔(未着弾の予測) |
| 掘り耐性 (dig_resistance) | 0〜1(生存0.7+掘削0.3) | そのまま | お邪魔10/20/30個落下後の本線生存度+掘削可能性 |

## 3. 火力系(threat採用=reach、他は参考)

| 指標 | 生の単位 | 正規化 | 意味 |
|---|---|---|---|
| 到達火力 (reach_fire_power) ★threat採用 | 送出お邪魔 個 | /72 | 実際の次/次々ツモ2手で到達できる最大火力(=実際に撃てる) |
| 即時火力 (immediate_fire_power) | お邪魔 個 | /72 | 今の盤面+最良1個追加で撃った時の送出お邪魔 |
| 潜在火力 (potential_fire_power) | お邪魔 個 | /72 | 理想2個追加の理論最大連鎖(過小評価あり・有利不利未使用) |
| 連鎖効率 (chain_efficiency) | お邪魔/色ぷよ | /2.0 | 密度あたりの火力 |
| 発火最小ぷよ (min_puyos_to_ignite) | 個(1〜6+) | 1−N/6 | あと何個で発火できるか(近いほど1) |

takapt定石 = 「各列に1色1個落として最良連鎖を探す」火力推定法(先行研究由来)。

## 4. お邪魔会計の評価単位(お邪魔個数)

| 用語 | 単位 | 説明 |
|---|---|---|
| 予告 (forecast) | 個 | 連鎖終了時に生成、まだ降っていない保留お邪魔 |
| 生成 (gen) | 個 | 連鎖得点 ÷ レートで換算した送出お邪魔数 |
| 相殺 (offset) | 個 | 自分の生成で自分への予告を打ち消した量 |
| net収支 (net_balance_capped) | 個(±72) | 相殺後の正味。1P視点でプラス=1Pが多く送った |
| 端数 (leftover) | 得点 | お邪魔換算の余り得点の繰越 |
| マージンタイム | 秒 | 試合経過で送出レートが上がる時間帯 |
