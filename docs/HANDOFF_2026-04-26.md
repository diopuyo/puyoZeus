## 8. セットアップ手順

### 初回セットアップ
```bash

cd /mnt/c/Users/ryouj/.gemini/antigravity/scratch/puyo_analyzer
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

### 主要依存
- Python 3.12 (3.11+ 必須)
- numpy, opencv-python, Pillow, pytest
- torch, torchvision (GPU 利用、CUDA 12.x)
- scikit-learn (重み学習用 LogisticRegression)
- yt-dlp (動画 DL)

### 実行例
```bash

PYTHONPATH=. ./venv/bin/python -m src.cli --help

# 単一フレーム解析

# 動画にオーバーレイ合成 (60s クリップ、音声なし)
PYTHONPATH=. ./venv/bin/python -m src.cli composite \
    data/verify/test_clip.mp4 \
    data/verify/test_clip_overlay.mp4 \
    --interval 0.5 --no-audio

# タイムライン解析 (50 試合)
PYTHONPATH=. ./venv/bin/python -m src.cli timeline \
    data/frames/video_02.mp4 \
    --boundaries data/verify/match_boundaries_v4/video_02/matches.tsv \
    --out data/verify/video_02_timeline.json

# テスト実行
PYTHONPATH=. ./venv/bin/python -m pytest tests/ -q
```
