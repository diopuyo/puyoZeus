1. **多様性強化** (動画ソース増 → CNN v7)

3. **構造的限界対処** (テロップ UNKNOWN 化・試合終了ロックダウン)
4. **統合パッケージング** (本番動画レンダ完成)

の 4 軸で Phase V を構成する。

## Phase V-2: ロジック層強化

**目的**: 画像認識誤差を時系列・物理・ネクスト誘導で後段補正する。

### サブタスク (依存順)

| ID | 優先度 | 内容 | 効果見込 |
|---|---|---|---|
| V2.1 | 最高 | **NextLinkedColorRefiner**: t-1 next_pair → t 新規ぷよ色を強制整合 | 色誤認 30%↓ 期待 |
| V2.2 | 高 | **PairAppearanceConsistency**: ペアで落ちる前提で 2 セル同時遷移を強制 | ペア欠落補完 |
| V2.3 | 中 | **ConnectivityShapeRefiner**: 連結同色グループ多数色で異色 1 セル補正 | 1-pixel ノイズ除去 |
| V2.4 | 中 | **StatefulBoardTracker 拡張**: 上記 V2.1-3 を統合した遷移ルール | 全体一貫性 |

### V2.1 NextLinkedColorRefiner 設計概要

```python
class NextLinkedColorRefiner:
    def refine(
        self,
        prev_board: Board,
        cur_board: Board,
        prev_next_pair: tuple[int, int],   # NextDetector 出力
        confidence_map: np.ndarray | None,  # CNN softmax (任意)
    ) -> Board:
        # 1. prev → cur の差分から新規出現セル抽出
        # 2. 新規 2 セルが prev_next_pair の色と一致するか確認
        # 3. 不一致 + 低信頼度なら next_pair の色に補正
```

統合点: `ImageReader.read_both_boards` の post-process、または `phase_u_render.py` のパイプライン。

### V2.2 PairAppearanceConsistency 設計

```python
class PairAppearanceConsistency:
    def enforce(
        self,
        prev_board: Board,
        cur_board: Board,
    ) -> Board:
        # 1. 新規出現セル数 == 1 なら矛盾
        # 2. 隣接位置 (上下左右) で「直前 EMPTY → 現在 EMPTY だが彩度高い」セルを推定
        # 3. ペアの相方として復元
```
