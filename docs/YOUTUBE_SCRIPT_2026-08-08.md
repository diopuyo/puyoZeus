## 前半 — ツール紹介 (0:00〜5:30)

### 0. つかみ (〜0:35) 【S:1】 映像A t=30秒
「この試合、どちらが有利だと思いますか」→ 3秒見せる → 判定バーを出す。
**対戦画面を見るだけで有利不利を判定するツール**だと明かす。

### 1. 何をするのか (〜1:50) 【S:2】
- 動画を入れると有利不利が出る。それだけ
- **入力は映像だけ** — ゲーム内部データは使わない → どんな配信にも乗る
- **何が有利かを人間が決めていない** — データから学ばせる
- **連鎖が終わるのを待たずに判定が動く**

### 2. 動かしてみる (〜3:30) 【S:2】 映像A t=10〜45秒
序盤=互角 → 中盤の組み合いで動く → おじゃまのやり取りで大きく動く。
下は評価値グラフ (将棋中継と同じ形式)。上の「主因」が判定の根拠。

### 3. なぜ作るか (〜5:30) 【S:3】
- ① 解説の補助 — 展開が速すぎて初見だと追えない
- ② **本命: 人が気づいていない評価軸を見つける**
  - GTR・階段といった**形の分類は一次的な判断材料にしない**
  - 形は手段で、測るべきは盤面の機能 (火力・厚み・受け・速さ)
  - **機能を測る指標だけ用意して、効くかどうかはデータに決めさせる**
  - 強者の癖や思い込みに引っ張られない軸が出るかもしれない

## 後半 — 技術 (5:30〜)

### 4. 盤面の読み方 (〜7:30) 【S:4】 映像Bに切替
画面の文字が読み取り結果 (R=赤、白丸=おじゃま)。判定方法は2つ併用:
- **色そのものを見る** — 速いが、ぷよの光沢で「空」と誤読する
- **小さなニューラルネット** — 光沢に強いが、学習してないものに弱い

→ 互いの弱点を補う。**ただし色を見るだけでは足りない**

### 5. 止まっている時だけ確定する (〜9:00) 【S:5】 映像C 連鎖場面
- 画面はほとんど常に何か動いている (落下・消去・発光・おじゃま)
- 動いている最中を読むと必ず間違える
- なので**「今どういう状況か」を別に判定**し、**止まっている時だけ盤面を確定**
- 動いている間は直前の盤面を凍結して使う
- 中途半端な盤面を確定させると、以降の判断が全部狂うため

### 6. 精度は測り方次第 (〜10:30) 【S:6】
- **2つの方法が同じ誤りをすると、突き合わせても一致してしまう**
- 一致率では検証にならないので、人手で正解を作った物差し (3,744セル) を用意
- 測定結果 **99.54%**
- 残り0.46%も調査済み。**居座り続ける誤りはゼロ**、全て1秒以内に自力で戻る

### 7. 画面の表示を正解に使う (〜12:00) 【S:7】 映像C 発火場面
- 発火直前の盤面をシミュレートすれば「何連鎖起きるはず」が計算できる
- 実際の連鎖数は**画面に表示されている**
- 突き合わせれば**人手ラベルなしで認識を検証できる**
- 実測: **9連鎖は8件中7件、7連鎖は9件中8件で予測が一致**
- **1週間前は実際8連鎖に対し予測1連鎖**という状態だった。
  原因は盤面に宙に浮いたぷよが混じっていたこと (落下中を「止まっている」と誤判定)。
  修正した結果が今の一致
- 人手の物差しと違い、**全動画に自動で適用できる**

### 8. 有利不利の学び方 (〜13:00) 【S:8】
- 正解は誰も教えてくれない → **試合の結末から逆算** (勝った側の盤面=勝ち)
- 勝敗は画面の勝利数表示から自動取得、**人手ゼロ**
- 効いている: おじゃま差 / 連結数 / 密度 / 最大連鎖数の差
- **「今どれだけ大連鎖を組めるか」だけでは勝敗はほとんど当たらない**
  - 大連鎖を持っていることと、勝つことは別
- 勝敗を決めているのは打ち合いの中身らしい → その指標を今つくっている

### 9. 正直に課題 (〜14:00) 【S:9】
- **① 自信過剰** — 「80%有利」と出した場面の実勝率は **64%**
- **② 大連鎖中に判定が逆転** ← 映像A t=57秒を見せる
  - 撃った直後は盤面が空になり、「これから撃てる火力」が低く評価される
  - 止まった盤面だけでは「大連鎖を組み終えた状態」と「撃った直後」を区別できない
  - **まだ直っていない**と正直に言う
- **③ 試合外の画面を読んでいた** — ロビーや順位表を盤面と誤読。
  **0.875%混入・調べた123動画すべてにあった**。検出と除外は実装済み

### 10. これから (14:00〜) 【S:10】 映像A 決着シーン
認識99.54% / 148試合分を処理中 / 判定は動くが較正がまだ。
目標は**配信にそのまま乗るツール** (OBSブラウザソース)。
本命は**人が気づいていない評価軸の発見** → 結果が出たらまた動画にする。
