# B3 v6 OBS 試験手順（2026-10-07）

レビューOK・v6採用済み。配布版は `D:/puyo_analyzer/packaging/build/PuyoLive/`。

## 起動してOBSへ表示

1. OBSを起動し、設定→映像→出力解像度を1920×1080にする（720pでの認識精度は未測定）。
   ゲーム映像を1920×1080に配置し、仮想カメラを開始する。仮想カメラの入力にオーバーレイ自身を含めない。
2. 配布フォルダの `puyo_live.json` を確認する。今回B3をONにした設定を配置済み。入力が違う場合だけ `device_index` を変更する。

   ```json
   {
     "source": "dshow",
     "device_name": "OBS Virtual Camera",
     "device_index": 0,
     "port": 8765,
     "output_dir": "output",
     "dshow_color_correction": "601to709",
     "b3_judgment": true,
     "b3_model": "app/models/b3/model.joblib",
     "b3_timing_table": "app/models/b3/timing_table.json"
   }
   ```

   入力番号の確認は、配布フォルダのPowerShellで `.\python\python.exe -m src.phase_j.launcher --list-devices`。
   相対パスは設定ファイルのあるフォルダ基準。
3. `PuyoLive.bat` をダブルクリックする。「入力確認中」「画面調整中 N%」を経て対戦を入力する。
   「試合待ち」が続くときは入力番号の誤りも疑い、`device_index` と仮想カメラの映像を確認する。
4. OBSにブラウザソースを追加し、URLを `http://127.0.0.1:8765/`、幅1920・高さ1080にする。
   ポートを変更した場合は起動ログのURLを使う。
   既存のブラウザソースを使う場合も、PuyoLive起動後に再読み込みする。
5. `output/b3_config.json` のモデルSHAと `search.version=b3_pair_potential_v2` を確認する。
   モデルSHA256: `6113e42b8d3aadad6251f0749ad09281d7c63a65fc09a4cc659e68694ee2903c`。
   設置・発火・連鎖・着弾・全消し・死亡確定・次試合・入力中断と再開で表示を確認する。

## 止め方と記録

起動コンソールで `Ctrl+C` を押し、終了後にOBS仮想カメラを停止する。
終了しない場合は今回起動した親PIDだけを指定し `taskkill /PID <PID> /T /F`。
設定ファイル、`output/`、症状の出た場面時刻を保存する。
B3をOFFにする場合は `b3_judgment` を `false` にして再起動する。
