## 1. zenchi 第43試合 2755〜2771秒

E23保存原票の全90評価を、同条件の再生に挿入した読み取り診断と照合した。
`logs/e24/ZENCHI_SCENE_TRACE.csv` が各評価の結論と停止条件、
`review_landing_branches.csv` が各着弾前の全枝の相殺量・投下量・残量である。
未実行の応手量は空欄であり、0個とは区別する。

- 2755.416667〜2770.583333秒の86評価は `uncertain_completion`。
  受け側最新連鎖 ID 9（2751.383333秒発火）の `predicted_final_board=None`、
  `predicted_final_score=0`、`predicted_chain_count=0` が継続していた。
  連鎖中または終了未確認なら `_death_boards` が `certain=False` にするため、
  複数着弾探索そのものを実行しない。
- 2770.283333秒に終了通知が出ても、静穏確認10フレーム（0.333333秒）の間は
  `end_confirmed=False`。2770.616667秒に連鎖中扱いが解除され、
  完走予測盤面の復元ではなく、その時点のSTABLE盤面で `certain=True` になった。
- 残る4評価（2770.616667 / 2770.650000 / 2770.683333 / 2770.850000秒）はすべて死亡。
  純受け171個、初回1手、両着弾前の最大相殺量は全枝0個。
  30個投下→残141個、さらに30個投下→残111個で全応手が窒息する。
  最初の証明は244ノード、2回目着弾の入力盤面は9枝。
- この90評価で `node_limit` / `optimistic_cancel` / UNKNOWNによる停止は0件。
  早い時刻の停止理由は応手過大評価や探索打切りではなく、完走盤面の欠落。
  なお短絡条件より後ろの条件を「評価して偽だった」と解釈しない。
- 内部の2P勝率は2770.616667秒に2%。表示はEMAにより2770.750000秒に初めて5%以下。
  E23で復元・検証済みの表示時刻と、今回の全出力等価性から確認した。

旧記録の `CHAIN_FIELDS` は発火前盤面を保存していない。
`_predict_completion` は `formula_read` の際に直前STABLE盤面を使うが、
この連鎖では予測0段・0点となり、完走盤面が作られていない。
UNKNOWNや探索打切りが今回の完走予測欠落を引き起こした、とする根拠はない。

## 2. 新規誤発火: q_7gc4TgFig 第13試合・2P

初回判定832.733333秒、交換38、純受け66個、初回2手、5,376ノード。
初回相殺2個・投下30個・残34個。2回目は63枝、相殺0〜8個・投下26〜30個で
全枝死亡と判定した。既存楽観探索の初回火力は1個だった。
これは1評価だけの誤判定で、次の832.766667秒には `surviving_response` へ戻る。

原映像832.733秒と記録STABLE盤面を突合すると、0起点 `(row=7,col=2)` は
緑なのに紫、`(row=7,col=3)` は黄なのに紫と記録されている。
同じ色は835.300秒のフレームでも確認できる。
色の不一致は2セルに限定すると主張しない。ここではこの2セルだけの感度を分離した。
`q_7gc4TgFig_input_probe.json` は同じ盤面・NEXT・手数・純受け量から
元の証明を再現した後、この2セルだけを原映像の色へ置き換えた診断結果である。
2セルだけの変更で楽観火力は1→18個、初回最大相殺は2→18個となり、
6,335ノードで `surviving_response`（死亡ではない）に変わった。
これは原映像の実際の9連鎖を完全再現した主張ではなく、元の死亡証明が
記録の色誤りに依存していることを示す局所感度である。
なお832.700 / 832.733 / 832.767秒にはNEXTも変動しているため、
次フレームの死亡解除を「2セルの認識が直ったため」とは扱わない。

実際には2Pが835.533333秒に発火し、848.100秒までに9連鎖40,240点
（70点/個換算で約574個）を撃つ。1Pの7連鎖19,840点を相殺して打ち返し、
852.600秒の原映像で2Pの勝利を確認できる。
主因は記録盤面の色不一致による応手過小評価であり、2Pの完走予測を信頼して
死亡にした例ではない（この時点の受け側は非連鎖中、`certain=True`）。

## 3. 新規誤発火: fcXG83vInDY 第5試合・1P

初回判定490.866667秒、交換14、純受け扱い597個、初回1手、8,031ノード。
初回相殺236個→投下30個→残331個、2回目相殺0〜1個→投下30個、
3回目相殺0個→投下30個で全応手死亡。各枝の値はCSVに保存した。

直前の交換13には1Pの9連鎖30,500点があるが、477.833333秒に
`confirmed_after_score` で閉じている。2Pの返しは478.400秒に交換14として始まる。
判定時の `_incoming` は交換14内の2P 41,800点・1P 0点だけを合計し、
41,800÷70の切り捨て597個を純受け量としている。
前交換の1P攻撃（約435個）が、2P側の未消化予告として持ち越されていない。

原映像477.833秒では、交換が閉じた後も2P上部に大量の予告おじゃまが残る。
478.400秒からの2P連鎖はこれを相殺してから1Pへ送り返す。
1Pは491.600秒に発火し、499.800秒までに6連鎖16,550点（約236個）で相殺、
502.000秒の盤面は窒息しておらず、537.867秒には1Pが勝利している。
主因は**交換境界をまたぐ未消化予告の欠落による純受け量の過大計上**。
応手236個は概ね実際の返しを捉えており、連鎖完走の予測誤りが主因ではない。

純受け量だけを162個／182個へ置き換える感度分析を保存した。
162は597から前交換1Pの435個を控除した値、182はさらに先行2Pの約20個を
控除しない場合まで含めた保守的な上側ケース。
これらは端数・落下点・既着地分を完全再建した実受け量の確定値ではない。
どちらも既存応手236個で相殺可能なので、597個を必要とする窒息証明は成立しない。
両ケースの実測診断結果は `optimistic_cancel`、0ノードで死亡否定となった。
