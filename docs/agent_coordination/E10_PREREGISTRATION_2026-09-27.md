# E10 固定設計と判定基準

基準: E9 `8aafa9c`。対象は既存 `--exchange-event-update` ON経路のみ。

物理量の選択: 既存の1回着弾上限30個・決定論的端数配置を再用し、累積得点を既存70点/個＋マージン換算、手数は実測連鎖演出残秒÷0.733秒のfloor＋1、既発火群は既存simulateで解消、G_feと暫定S3をlogit等重み平均、応手不足時の敗者勝率は0.02。

確定S3は既存の終了・着地復帰経路を維持し、確定通知の瞬間に既着地盤面へ再投下しない。
応手探索の天井設置は連鎖解消後に窒息を判定する（E10のみoptional引数ON、旧指標の既定値は維持）。
応手探索幅は1手の全配置数（縦2×6＋横2×5＝22）に固定し、8候補の枝刈りによる「返せる77個を8個と見積もる」誤固定を避ける。

- A: 2695〜2696秒の確定時刻から0.5秒以内に2P勝率≤0.35。
- B: 記録上2807.617秒の2連鎖ダブル確定以降、決着まで1P勝率≤0.10。
- 回避不能死: 固定した側がその試合に勝った件数0を目標、許容5%以下。未完試合も発火件数へ含め、勝敗未確認を別計数する。
- zenchi公式第41〜57試合、終盤1/3の表示符号と勝者の一致率がE9以上。
- q log lossの増加≤0.005。q/fcX/miaの±3帯反転数≤E9×1.2。
- 関連テスト全合格、OFF 140〜165秒の動画・表示NPZ・確定NPZのSHA一致。
