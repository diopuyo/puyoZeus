各側の連続同一STABLE盤面を圧縮し、試合内外の境界を跨がず、中央値時刻差2秒以内の
可視盤面一致を順序保存LCSで対応した。隠し段は色画像から直接読めないため対応条件から外した。
一致アンカーの間では、全可視セルの占有位置が同じで、色差が1セルだけの盤面も対応した。

  611差の内訳は **時刻ずれ312 + 隠し段推定69 + 対応後可視色差0 + 未対応230**。

## 2. 色のウォームアップ

DirectShow入力の起動、`--input-config` JSONの機器名/index変更、入力喪失後の復帰で実行する。
1秒ごとに設定を再読込し、変更時はcaptureを閉じ、認識履歴・評価履歴・較正状態を初期化する。
同一カメラ内の入力切替は設定nameも変える。自動で実機serialを取得する実装ではない。

既存パイプラインのOnlineHsvCalibratorを複製・resetして信頼条件とis_readyを再用する。
通常設定は50サンプル/色、HSVと確定色の一致条件（既存のrequire_cnn_proba=False）。
4色それぞれがreadyになったら終了し、`config/device_calibration/sha256(name:index).json` に保存する。
次回は12サンプル/色で保存HSV範囲との重なりを確認し、色構成・範囲の変化時は50へ戻す。
なおクラス単体の厳格既定値（CNN>=.99、200/色）はこの40秒で黄55しか集まらず未収束だった。
新規の閾値緩和ではなく、実際に使用中の段階2条件を引き継ぐことでこの問題を避けている。

既定は `verification_only:true`。B4でも補正による改善がなく、B5でも主要差を色境界で
説明できないため、見え方の検証と保存だけで終える。`false` 明示時は範囲を適用し、
補正前の認識履歴を破棄してから公開する。補正の精度改善を保証するものではない。

ウォームアップ中は盤面通知を評価へ渡さず、DTOの全勝率と層別値を未取得にする。
`display.input_status` / `calibration_progress` / `message` と最小HTMLで
「入力確認中」「ぷよ画面なし」「色を較正中 ○%」を表示する。
FIFO制御順と公開直前のロック内確認により旧評価の復活を防ぎ、validator R23でも拒否する。

実動画検証（2600秒開始、検証モード、各1回、モデル初期化・入力画面検証の時間を除く）:
- 初回 **5フレーム/0.167秒**、青72・緑81・黄54・紫63サンプル（各50以上）。
- 保存後 **3フレーム/0.100秒**、青24・緑27・黄18・紫21（各12以上）。
同じ区間での再確認であり、機器間差・暗い画面・4色が揃わない開始局面の所要保証ではない。
実機の抜き差しは未実施。疑似入力の切替・復帰・未収束・勝率抑止はテストで検証した。
再実行: `scripts.verify_live_b5_warmup`。試験profileはlogsに隔離した。

## 3. MC診断のみ

B4の実要求9件を記録から再構成し、同じ盤面/NEXT/閾値/時間予算で60/30/15回を各1回探索。
1要求は1P・2Pの直列合計。nice0、開始loadavg8.599、終了7.827で、高負荷時の診断である。
起動・IPCは含めない。元の通知列上で所要時間後の次通知を完了時点とする反実仮想であり、
実ライブの採用実績ではない。相手側の更新だけを無視し、自側盤面/NEXT/試合/期限条件は維持した。

- 60回: 要求所要 **P50 2252.301 / P95 3528.243 / P99 3710.852ms（n=9）**。
  片側探索はP50 1150.359 / P95 1990.947 / P99 2407.457ms（n=18）。
- 確定盤面更新間隔: 1P **633.333 / 3893.333 / 14202.667ms（n=23）**、
  2P **600.000 / 2540.000 / 6193.333ms（n=37）**（P50/P95/P99）。
- 両側世代なら60/30/15回すべて採用 **0/9要求**。
  片側世代ならそれぞれ **0/18、6/18、9/18側結果**。
  60回では期限切れも **7/9要求** あり、世代だけを片側化しても間に合わない。
- 30回: 所要 **886.122 / 1555.900 / 1700.255ms（n=9）**。
  60回に対する確率絶対差は平均 **1.852ポイント**、P95 **6.667ポイント（n=18）**。
- 15回: 所要 **412.919 / 941.490 / 1088.520ms（n=9）**。
  同じ確率絶対差は平均 **3.704ポイント**、P95 **13.833ポイント（n=18）**。

60回の値も正解値ではなく、削減差は精度損失の確定値ではない。
片側だけ採用できても両側を使う合成優位を現在値にはできない。探索数・本番採用条件は維持した。
再実行: `scripts.measure_live_b5_mc`。集約: `scripts.summarize_live_b5`。
