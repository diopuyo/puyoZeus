# E3b 実装・集計の細部決定

- 発火側不明はS1 record生成前に棄却し、直近G_feを維持；診断は既存events.jsonlの構造を変えずevents.diagnostics.jsonへ件数と時刻を保存（同じ試合・理由・観測の再通知は一件）。
- 入力不足は発火前盤面・snapshot・特徴・M0・得点確定を対象に保護し、S3不可ならS1、S1不可ならG_fe、G_fe不可なら直近G_feを保持；評価器の検証は変更しない。
- OFF不変確認はqの140–165秒・750フレームを修正前後コードで実レンダし、mp4・display.npz・settled.npzのSHA-256を比較。
- fcX/miaの参考M3は既存認識ラベルを既存収集PLANの全区間へ結合（fcX: [5290,7219)、mia: [4020,5352)）；qは事前登録どおり独立勝敗4区間。
- q/miaは旧コードで全900秒完走しており、両側Falseは入力検証で必ず例外になるため発火側不明は0件；再レンダはfcX ONだけ。
