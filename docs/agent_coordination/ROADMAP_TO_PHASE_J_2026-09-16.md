## 3. 組み替え

### 原則

- **Phase J の経路にある仕事を優先する。** 重い観測層の完走は、そこに乗らない限り後回し。
- **品質は制約条件。** 速さのために判定を変えない。GTで測れない改善を採用しない。
- **合わせ込みを外す。** 動画ごとの手作業が残る限り一般化を主張しない。

### P1. 本番経路の分離と速度確保【最優先・Phase J に直結】

検証用の重い経路 (43ストリーム/4.2GB) と本番の軽い経路を分ける。
既に決定済みの方針 (2モード分離・重い指標の二層設計) をここで実装する。

- 目標: 判定に必要な出力だけ。30 fps・RAM 数GiB。
- 現状比: 速度6倍。認識単体25.67fpsが根拠。
- 副次効果: 4並列以上が成立し、5動画の一巡が数時間になる。G3も速くなる。
- 検収: 軽量経路と重い経路で**判定出力がバイト一致**すること。速度のために判定を変えない。

### P2. 試合境界で範囲を自動決定【一般化の土台】

フレーム番号の直書きをやめ、試合の開始と終わりから範囲を決める。
検出は既に動いている (video_38の処理済み区間で試合進行8回、動画55分で約43試合)。

- 効果: 残り3動画が「繋ぐ」から「回すだけ」になる。
- 効果: 途中切れの問題が消える (短縮試験2回の失敗原因)。
- 効果: 材料が8試合から約43試合へ。序盤中盤の学習材料が5倍。
- Phase J への寄与: 未知の入力で範囲を自分で決められることが前提条件。

### P3. 物差しの確定【品質の前提・user判断が要る】

13場面の人手GT認定。本日2件確定、残り11件。
GTが無ければ P4 の改善を測れない。**唯一 user の判断が必須の項目。**

### P4. 序盤中盤の判定精度【本丸】

AUC 0.52-0.55 を上げる。Phase J で表示する価値を決めるのはここ。
P1で速く回せ、P2で材料が5倍になり、P3で測れるようになってから着手するのが順当。
先にやると、測れないまま指標をいじることになる。

既知の未解決も同じ工程で扱う: ±100張り付き、方向反転、交換会計。

### P5. 5動画での一般化確認【G3の完了条件】

P1の軽量経路で回す。重い観測層は、特定の欠陥を診断するときだけ選択的に使う。

### P6. Phase J 実装

設計は完成済み。P1〜P5 が満たされていれば、実装と接続に集中できる。
