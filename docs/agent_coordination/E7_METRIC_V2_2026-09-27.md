# E7 表示平滑化・計測定義v2（再生前固定）

E6bの評価器・参加連鎖・終了判定は保持し、ONの確率→スコア変換後に
既存EMA_ALPHA=0.25を適用する。認識フレームごとに表示を更新し、描画間引きに
依存させない。初期値はOFFと同じスコア0・確率0.5。OFF同様に試合境界で
EMAを初期化しない。評価欠測時の既存フォールバックは維持する。
display_advは実表示、display_p1とeventsのp1は平滑化前の評価値を保持する。
これによりEMAによる見かけの更新を鮮度改善として数えない。

## v2の定義と理由

- M4: 試合内で+EVEN_THRESHOLD以上と−EVEN_THRESHOLD以下を移る回数/分。
  EVEN_THRESHOLDは既存の3.0をimportする。中立域を挟んだ反対側到達を1回とし、
  中立域内の往復と試合境界を数えない。全表示フレーム/30fps/60を分母とする。
  理由: ±3のEVEN表示に相当する微小揺れを有利側の反転と数えない。
- M2: E6b撃ち合いをOFF/ON共通の物理区間とし、全参加連鎖の最終end_signal_secを
  起点とする。閉鎖時刻以降、次の撃ち合いまたは試合末より前の最初のG_fe評価を
  共通目標とし、平滑化前p1を既存変換でスコア化する。各モードの発火時刻より
  厳密に前の最後の実表示スコアと目標の中点へ、目標方向に初めて到達する時間。
  終了時点で到達済みなら0秒。探索は終了合図以降・次の発火または試合末未満。
  変化量5.0未満はモード別に対象外として件数を保存する。欠測理由・未到達も
  全件保存し、未到達は∞として中央値に含める。理由: OCR確定の遅れと
  微小変化による遅延を除き、実際の表示反応を同一の終了合図・静止目標で測る。
- M1(i)、M3、S3内部/実表示到達・S1滞在はE6b定義を維持する。
  鮮度もON=display_p1、OFF=adv_raw_lastの評価値ベースを維持する。
- OFFはE5が参照したlogs/e3/rendersの保存済みOFFレンダ値を使用する。

## 統括固定ゲート

M2中央値ON≤OFF、M4 ON≤OFF×1.1、qのM3 log loss ON≤OFF+0.005、
M1(i)≤20%、S3内部/実表示到達率≥80%、S1滞在中央値≤発火から最終終了の
中央値+2秒、各動画の最長同値ON≤OFF+1秒。合算値だけで鮮度を合格にしない。
全ゲート合格時に関連テスト・OFF25秒（q、140–165秒）SHA一致を確認する。
