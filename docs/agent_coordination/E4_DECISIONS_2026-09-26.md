# E4 固定条件

E3事前登録の対象・ラベル・M2〜M4を維持し、鮮度は同値割合ON≤OFF+0.05かつ最長同値秒ON≤OFF、未達時はM3/M4を判定保留、M1は撤回型≤20%で判定する。

細部決定: 30fpsの終了合図から10フレーム経過を猶予とし、静止評価はOFFのper-side-settled設定と同じ確定盤面更新タイミング、鮮度は全フレーム隣接対の厳密同値・同値連続フレーム数÷30・値の変化回数/分で測定、M1(i)はS3時点で存在した終了合図の撤回、(ii)は最初のS3後の追加参加（重複可）とする。

M2の着地後G_feは密な表示列から同試合・次の撃ち合い前の最初の値を取得する（早期close後も従来の着地後目標を維持）。着地なしの相殺区間はclose以降の最初のG_feを用いる。

F2の終了はS3発火・終了合図を前提とせず、全参加連鎖の得点確定後の両側盤面で閉じる（10フレーム待ちはS3発火だけに適用）。
