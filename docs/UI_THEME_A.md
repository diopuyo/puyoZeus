# A 対戦ゲージ

表示設定のテーマ「A 対戦ゲージ」、または既存設定の `overlay.theme` を
`"battle-a"` にすると有効になる。既定テーマは変更していない。
`"normal"`、`"esports"`、`"pop"` へ戻せば従来の表示に戻る。

見本の配置は `layout: "l"`、`scale: 80`、`corner: "top-left"`、`band: true`。
1920×1080 のうち右384px・下216pxを使う。既存の配置・表示項目設定も維持する。

勝率は既存の `winrate_switch.line1` の選択経路をそのまま使い、
整数表示だけを丸める。全体グラフも既存の履歴を使う。
撃ち合いは既存の `practical.source` / `winrate_switch.v49f_active`、
決着は既存の確認済み勝敗、待機は既存の入力・保留状態に従う。
別の勝率箱、判定の詳細、試験用パネル、式の枠の座標は A では表示しない。

直近30秒の変化は表示済み勝率との差。記録開始から30秒に満たない間は、
最初に受け取った値との差になり、札の title に比較間隔を入れる。
1.2秒以内に12ポイント以上動いた時、押された側の板が揺れる。
演出の間隔は1.8秒以上。試合変更・時刻逆行・入力待ちで履歴と演出を戻す。
短期線は30秒・最大4096標本を保持する。勝率の計算・公開データには戻さない。

動く属性は transform と opacity のみ。ゲージは scaleX と境界の translateX、
板と状態札とゼウスくんは単発の演出。静止時のループはない。
ゼウスくんは既存 WebP の先頭コマを画素を保って静止 WebP にしたものを使う。
OS の「動きを減らす」設定にも従う。

字体は `src/phase_j/fonts/` に WOFF2 と各 OFL 1.1 許諾文を同梱する。
Dela Gothic One と Noto Sans JP Bold の全文字を保持している。
取得元・元ファイルの SHA-256 は同ディレクトリの README.md に記載。
読み込めない場合は Yu Gothic UI / Meiryo / sans-serif に戻る。
配布用資産一覧は既に `src/phase_j` 全体を含むため追加設定は不要。

## 全画面ゲームに重ねる横長版

`overlay.layout: "ribbon"`、`overlay.theme: "battle-a"`、`overlay.mascot: true`。
本体の既定は左706px・上700px、幅500px・高さ216px。
ゼウスくんは132px角で本体の左＋2px・上−128px、吹き出しは左＋146px・上−100px。
VS、太いゲージ、直近30秒の札と短い線を並べ、撃ち合い・決着の札を右上に出す。
短い線はこの組み合わせで既定ON。以前保存した `recent: false` があれば true にする。
L字版と旧テーマは従来どおり。横長版の `scale` はゲームを縮小しない。

設定画面のドラッグ・x/y入力をそのまま使え、ゼウスくんと吹き出しも追従する。
以前の x/y が残っている場合は中央へ戻すか x=706・y=700 にする。
既存の重なり注意領域は変更せず、横長Aでは本体の影・吹き出し・状態札も検査する。
2026-10-27の採用判断に従い、本体・影とゼウスくんが盤面端を避ける相対位置に調整した。
既定位置ではゼウスくん左708px・上572px、吹き出し左852px・上600pxになる。
本体・影を中央の隙間に収める本体 x は705〜707px。
上のNEXT領域と下のWIN領域を避ける本体 y の範囲は678〜711px
（ゼウスくんの132px外接矩形と8px影を含み、単発演出の途中を除く）。
既存の注意領域は保守的な矩形であり、実ゲーム画面での最終確認にも使う。
