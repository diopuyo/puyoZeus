# puyoZeus Live 0.6.0 — リリースノート下書き

未公開・未承認。最終 ZIP の版名、SHA256、モデル、C5 の結果を確定してからこの冒頭を外す。ファイル名の変更だけで RC を正式版にしない。

ぷよぷよeスポーツの対戦映像から盤面を認識し、有利不利の推定を OBS に表示する非公式ツールです。ゲームの権利者・開発元との提携や承認を示すものではありません。

## この版でできること

- OBS 仮想カメラなどの映像入力から盤面を認識し、推定をブラウザソースに表示。
- 初回案内と設定画面で入力・表示を調整。専用窓が利用できない場合はブラウザーへ退避。
- ゼウスくんの表情、表示の配置・内容の調整。
- ZIP 展開で導入。Python と実行用モデルを含む署名なし配布を予定。

## 既定の設定

ソースの基点は `412bef5d8052770ad40f42c96454240a424069ff`。本作業で製品の既定値は変更していない。

- 配布設定の詳細は `docs/RELEASE_DEFAULTS_20261101.md`。OBS 仮想カメラの色補正は `601to709`、他の機器は `off`。利用者の明示指定を優先。
- B3 の ensemble と連鎖・交換の評価設定を利用。通常の表示ポートは 8765、モデルの評価遅延設定は 200 ms。
- 専用窓のソース旗は既定 OFF。配布物の `distribution.json` で ON にする設計。最終 ZIP 内の値を公開前に照合する。
- 表情の自動切替は配布の既定で ON（11/2 user 決定）。利用者が設定から OFF にできます。
- 窓の × は非表示。終了は画面内または通知領域の「終了」。

## 既知の制約

上級者対戦のデータに基づく推定であり、勝敗や強さを保証するものではありません。別タイトル・初級者対戦の精度は未保証。16:9・1920×1080 の入力を想定し、画面配置、色、解像度、遅延に影響されます。認識が安定しない場合、表示の保持や遅延が起こります。

署名なしのため SmartScreen が表示される場合があります。正しい取得元・版名・SHA256 を確認した上で判断してください。保護機能全体の無効化は不要です。

Windows / OBS の確認済み版、最低環境、新しい Windows での初回導入（C5）は公開前の確認待ちです。216 本の次期モデルはこの版の採用確定事項には含みません。
