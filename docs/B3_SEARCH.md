# B3専用の近未来火力探索

2026-10-06の規則修正に基づく `b3_pair_potential_v2`。本番の
`indicators_v2.near_future_fire_power` と既存のRustビーム探索は変更しない。

- 1手は2個組。NEXT/NEXT2の既知セルを固定し、未知セルは使用可能色から選ぶ。
  同色組・異色組の配置には既存Rust配置関数を使う。
- 隠し段への設置は可能。色ぷよ・おじゃまとも隠し段では消去せず、可視段へ落下後に消去可能。
  配置→連鎖を最後まで解決→row1・col2の窒息判定の順とし、死亡手の得点はQに入れない。
  `resolve_before_death` は互換用引数で、値によらずこの順序を適用する。
- 未確定の試合色は観測と両立する4色集合を保持する。同一盤面は1候補に統合し、
  到達経路の可能な色集合を併合する。途中で5色を混用する経路は作らない。
  入力自体が5色を要求する場合は満杯と区別し、学習行のQ/Kを推定不能の欠測にする。
  500件監査ではそのケースも除外せずQ=0の保守的参考値として不足に含める。
- 展開した全配置の実発火得点を記録する。QはH組以内の最大単発得点であり、
  累積得点でも、潜在得点でもない。
- 次のビームには未発火の積みと発火残骸の枠を確保する。
  潜在評価は1個追加連鎖試行の最大生得点。B3専用の上記規則で生存する候補を使う。
  軽量設定では可視段の同色隣接数で予備選抜し、発火上位と未発火枠を補う。
  幅・予備選抜倍率による近似なので、理論上界の保証や幅に対する単調性はない。
- 採用設定は `src/b3_search.py`、学習行は末尾の `search_version` とmanifestの
  `search` に記録する。既存Q/K系列の列名・換算・正規化は保持する。
  版列は側交換で不変のメタデータで、学習特徴への変換対象には入れない。

## ビルドと再計測

WSLの指定venvを有効化し、`native/puyo_core` で `maturin develop --release` を実行する。
更新前の拡張では明示的なエラーにし、旧探索へのフォールバックを行わない。

固定500件の比較は `python -m scripts.b3_search_redesign_eval`。
幅は `--widths`、潜在評価の予備選抜倍率は `--shortlists`（0は全候補）。
実量はPC2調査の `response_generated`、旧Qは `Q_old`、参照手数は `H_med`。
過大はQ>実量を全件計上し、+30個/+100個超も併記する。

特徴全体は `python -m scripts.b3_search_feature_bench --capture` で公開時間門動画
`b3_zenchi_s1` の500状態を因果的に復元し、同モジュールの幅・倍率引数で測定する。
各状態の直前に探索・静止指標キャッシュを空にする。動画I/O、状態再生、モデル推論は含めない。
計測原票・全設定・採用理由は `D:/puyo_analyzer/b3_data/codex_tasks/search_redesign*` に保存する。
