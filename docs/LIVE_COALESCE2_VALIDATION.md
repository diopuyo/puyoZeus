# live の内部キーと公開試合番号の分離

基準は `341b8539`（l）。`live_public_match_number` は既定 OFF。
旧 `recovery_boundary_coalescing` の実装は変更せず、同時指定は拒否する。

## キーの責務

- `game_idx` と評価行の `game` は従来の内部キー。強制境界と得点境界の両方で必ず進める。
- 境界ブロック、死亡確定、撃ち合い評価器、B3、EMA、決着保持の状態遷移は内部キーを使う。
- 入力回復だけの境界を公開番号から除き、得点境界・別機器・機器不明の境界は公開番号も進める。
- 公開 DTO の `identity.match_id` と公開監査行の `public_game` が公開番号。評価保存行は変更しない。
- 「次試合待ち」は従来の `match_active`・保持期限・入力状態で決める。公開番号の据え置きを旧評価の保持根拠にしない。
- l の `terminal_hold_input_recovery` による限定保持も同じ内部キーと境界理由で動く。得点境界で解除する。
- SSE の決着送出照合には公開番号と元の取得時刻を使う。保持状態の解除・遅着拒否は従来の内部キーで行う。
- UI は入力保留・試合待ち・評価欠測で旧数値とアニメーションを消す既存処理を維持する。
