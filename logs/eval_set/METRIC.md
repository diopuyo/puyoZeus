## 指標 (試合ごとに計算し、57試合を等重みで平均)
1. **M_time (主)**: 試合内の全表示フレームの log loss の平均 (30Hz 等間隔なので時間加重平均と同じ)。
   集計 = 57試合の M_time_g の単純平均。
2. **M_cp25 / M_cp50 / M_cp75**: 試合長 D_g = 終了−開始 の 25/50/75% 時点 (開始 + q·D_g) 以前で最後の表示フレームの
   log loss。集計 = 57試合平均。**M_cp** = 3時点の平均。
3. **M_agree**: 現行 zenchi 一致率と同じ定義を57試合へ拡張 = 各試合の終盤1/3 ([開始+2D/3, 終了)) の全フレームで
   sign(display_adv) が勝者側と一致したフレーム数 / 総フレーム数 (フレーム加重、0 は不一致)。
4. 参考: M_frame = 窓内の全フレームをプールした log loss (q と同じフレーム加重の形)。

## ゆらぎの測り方
- 再学習ゆらぎ: 再判定の10モデル (旧/補正 × random_state 0〜4、wt_nextfix models/rejudge) を同じ記録で再生
  (wt_nextfix の再生器そのまま、表示の切替平滑なし)。同じ特徴の5通りの 標準偏差 (ddof=1) と 範囲。
  比較対象: q の同じ10構成の値 (wt_nextfix logs/next_shift_rejudge/GATE.json)。
- 標本ゆらぎ: 試合単位のブートストラップ (57試合を復元抽出、10,000回、乱数種 20261001)。
  単一構成の 95% 区間と、同じ試合で比べた対差 (構成A−構成B の試合別差の平均) の 95% 区間。
- 最小検出差 (MDD、両側 α=.05・検出力 .8 → 係数 2.80):
  (a) 対の標本ゆらぎ: 2.80 × SE(試合別対差の平均)、(b) 再学習ゆらぎ: 1構成どうし 2.80 × √2 × σ_seed、
  5 seed 平均どうし 2.80 × √(2/5) × σ_seed。
