## ラベリング 2 つの軸

### A. cell の色ラベリング (= CNN 色分類モデル用)

各 cell の真の色をラベル付けします。

1. **赤枠 cell を探す** (= CNN 予測が違うかも)
2. **クリック** で選択 (青枠に)
3. **色キー** で設定 → 緑枠 (修正済)
4. 全部赤枠が消えたら次へ

### B. フレーム状態ラベリング (= 新機能 X-2、 1P/2P 独立)

**1P と 2P が別々の状態をとる可能性** (例: 1P 連鎖中、 2P ツモ落下中) に対応。

#### 1P 用キー (= 小文字)
| キー | 状態 | 例 |
|---|---|---|
| **n** | STABLE (通常) | ぷよが盤上に静止、 試合中 |
| **c** | CHAIN (連鎖中) | 連鎖アニメ + ぷよ消去 |
| **f** | EFFECT (演出中) | 全消し演出、 連鎖カウント、 相殺の半透明緑 |
| **j** | おじゃま落下 | お邪魔ぷよが降ってくる |
| **t** | ツモ落下 | ぷよが落下中 |
| **m** | MENU (試合外) | メニュー画面、 試合間 |
| **k** | **Skip (学習除外)** | 何の状態かわからない |

#### 2P 用キー (= Shift+ / 大文字)
| キー | 状態 |
|---|---|
| **N C F J T M K** | 大文字で 2P 側の状態を設定 |

**重要**: K (Skip) を選んだ side では cell ラベルは保存されません。 ただし frame state ラベルは 1P/2P 別々に必ず保存されます。

#### 落下中のぷよの扱い
- ぷよが盤面に着地して静止している cell = **本来の色** (= R/Y/P/B/G/O)
- 落下中で位置が動いているぷよ = **UNKNOWN (X キー)** (= 色不明扱い)
- 演出/連鎖で完全に色が見えない = **UNKNOWN (X キー)**

### フレーム状態 (= 1P/2P 独立)
| キー | 1P 側 | Shift+キー | 2P 側 |
|---|---|---|---|
| n | STABLE | N | STABLE |
| c | CHAIN | C | CHAIN |
| f | EFFECT | F | EFFECT |
| j | OJAMA_FALL | J | OJAMA_FALL |

### 移動 + 操作
| キー | 動作 |
|---|---|
| ↑↓←→ | cell カーソル移動 |
| Tab | 1P ↔ 2P |
| Space / Enter | 保存して次フレーム |
| Shift+Space | 前フレーム |
| Ctrl+S | 保存のみ |
| Ctrl+Z | 元に戻す |
| Q / Esc | 終了 |

## おすすめのラベリング順序 (= 1 フレームあたり)

1. **1P state を判定** → 小文字キー (例: 1P が連鎖中なら `c`)
2. **2P state を判定** → Shift+キー (例: 2P がツモ落下中なら `Shift+T`)
3. 両方 SKIP 設定なら → **Space で次へ** (= 全 cell ラベル不要)
4. それ以外なら → 各盤面の **赤枠 cell を色キー で順次修正**
   - 落下中ぷよ = **X (UNKNOWN)** で OK
   - 通常静止ぷよ = R/Y/P/B/G/O
5. 全部直したら **Space で保存 + 次へ**

これで 1 フレーム 30 秒 〜 1 分 の目安。

### よくある状態の組み合わせ

| シナリオ | 1P 状態 | 2P 状態 |
|---|---|---|
| 両方とも通常時 (= 普通の対戦中) | n | N (Shift+N) |
| 1P が連鎖中、 2P は普通に動いている | c | N |
| 1P 連鎖中、 2P もツモを落としている | c | T |
| 全消し演出 | f | F |
| メニュー画面 (= 試合外) | m | M |
| 何が起きてるかわからない | k | K |

## トラブルシューティング

### GUI が文字化けする
→ 日本語フォント install: `wsl -d Ubuntu sudo apt install -y fonts-noto-cjk`

### GUI が表示されない (= X11 接続失敗)
→ `wsl --shutdown` で WSLg 再起動

### ラベル付けの途中でやめたい
→ **Q キー**でいつでも終了。 Space で保存したフレームまでは保存済み。

### 連鎖中なのに「赤枠が大量に出る」
→ **K キー (Skip)** で「このフレームはラベリングしない」 と設定して Space。 学習データから除外されます。

---

## ヒント (= 効率化)

- **CNN がすでに合っている cell は触らない**。 赤枠だけ修正。
- **K キー積極利用**: 「連鎖中で色が分からない」 「演出で見えない」 は迷わず K (Skip)。
- **frame state を最初に決める**: N か K かを最初に押すと全体の判断が早い。
- **1 動画 30 frame で 15-30 分**目安。 5 動画で 1.5-2.5 時間。
